# DXS 산출물 파일명과 주간 릴리즈 운영

- 사용자 효과: 새 관리 산출물이 `DXS-[사업코드]-[문서유형]-[파일제목]-[YYYYMMDD]-vX.Y.[확장자]`로 일관되게 생성·점검되고, 팀원은 개선 PR을 수시로 올린 뒤 일요일 통합·월요일 배포 주기로 업데이트를 받을 수 있음
- 변경 범위: 공통 산출물 버전 정책과 이력 템플릿, 7개 소비 스킬 복사본, HWPX 경량 생성·검사·수용 테스트, README·팀원·배포자·PR·HTML·ax1-work 설계 안내, 빌드 불변조건과 릴리즈 메타데이터
- 제외 범위: 기존 산출물 일괄 개명, 제출기관·계약·고객 필수 파일명 대체, 내부 용어사전 DOCX와 실제 프로젝트 산출물의 저장소 반입, 미확정 신규 코드의 임의 추가
- 검증: HWPX 정상·거부 수용 테스트, 전체 빌드와 개별 ZIP 자원 동기화, 공식 스킬 빠른 검사, HTML 구문·Python 컴파일·Git diff 검사를 수행
- 호환성: 기존 파일은 그대로 유지하고 다음 정식 개정에서 한 번 전환함. 새 HWPX 경량 출력은 DXS 전체 파일명과 정확한 `vX.Y`를 요구하므로 스킬 v0.4.0으로 표시함
