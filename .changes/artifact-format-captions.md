# 산출물 서식: 표·그림 캡션 아래 배치 규칙과 검사, 표기 기본값·용어집 템플릿

- 사용자 효과: ① 표·그림 캡션을 모두 **대상 아래**에 두는 규칙을 확정하고 형식을 `[표 1-1] 제목` / `[그림 1-1] 제목`(장-순번, 10pt 보통, 가운데, 위 3pt/아래 10pt)로 고정함. 캡션은 자동 생성하지 않고 사람이 적음. ② apply 가 사람이 적은 캡션 문단의 서식을 통일하고 표 위에 놓인 표 캡션을 표 아래로 옮김. ③ check 가 캡션이 있을 때만 서식·위치·번호 연속성·장 번호 일치·본문 미참조를 위반으로 보고함. 캡션 없는 표는 위반이 아님. ④ 숫자·날짜 표기 기본값(천 단위 콤마, 단위 붙여 쓰기, `YYYY-MM-DD`)과 한/글 후처리 항목(쪽번호 하단 가운데, 화면 캡처 마스킹)을 규칙 문서에 추가하고 과제별 `용어집.md` 템플릿을 제공함
- 변경 범위: bizplan-artifact-format — SKILL.md, references/01-format-rules.md, 04-content-authoring.md, assets/glossary-template.md(신설), scripts/hwpx_format.py(캡션 상수·판별), apply_artifact_format.py(retrofit_captions), check_artifact_format.py(캡션 검사 4종). build_artifact.py 는 변경 없음
- 제외 범위: 캡션·번호 자동 생성 없음. 그림 개체 생성·그림 캡션 위치 이동 없음. 숫자·날짜·용어 표기의 자동 검사·교정 없음. 영문 약어 풀네임 규칙 미정. 쪽번호는 스크립트가 넣지 않음
- 검증: 익명 샘플(원고에 `[표 1-1] 제목` 을 표 아래·위에 직접 적음) 생성 → 서식 적용 단계가 캡션을 가운데·10pt·위3/아래10pt 로 맞추고 표 위 캡션을 표 아래로 이동, check 위반 0·XML 적합. 번호 건너뜀·장 번호 불일치·미참조 캡션 샘플은 check 가 `캡션 번호`·`캡션 참조` 위반으로 보고. 캡션 없는 표는 위반 없음. `python scripts/build_release.py` 통과. 한컴 시각 검증 대기
- 호환성: 캡션이 없는 기존 문서는 종전과 같이 통과함. 캡션을 적은 문서만 새 검사 대상이 됨. 생성·적용 흐름과 옵션은 종전과 같음
