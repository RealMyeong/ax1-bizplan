# 산출물 본문: 문서 자체에 대한 정보만 남기는 내용 규칙 신설

- 사용자 효과: ① `bizplan-artifact-format` 에 본문 내용 규칙이 없어 서식만 통제되고 내용은 무규칙이었음. `references/06-content-rules.md` 를 신설해 **산출물은 그 문서가 확정한 정보의 기록이며 본문에는 그 문서에 대한 정보만 쓴다**를 원칙으로 고정함 ② 작업에 대한 것(작성 과정·사용자 지시·동의·검증 절차), 읽는 사람에 대한 것(독자·활용 방안·기대효과·공유 대상), 진행 상태에 대한 것(미확정·결정 필요·담당자 요청·후속 일정), 근거에 대한 것(출처 파일명·경로)은 본문이 아님. 출처는 참조문서 표에 문서명·버전으로 적음 ③ 값이 없으면 칸을 비움. 없는 수치·임계값·담당자·승인을 채우지 않고, 비어 있다는 사실을 문장으로 설명하지도 않음 ④ `1.1 목적` 을 정의함. 이 문서 자체에 대한 설명이며 무엇을 확정하는가·어느 범위인가·어느 기준을 따르는가 세 가지만 씀. `화면 설계의 확정 기준을 담당자가 공유하고 … 확인할 수 있도록 작성한다` 대신 `AVIS 운영 화면 12종의 화면 구성, 항목별 표시 규칙, 항목별 원천 데이터를 확정한다` ⑤ 쓰지 않는 문형을 다섯 유형으로 명시함. 문서가 자기 목적·작성 방식을 말하는 문장, 독자·효과를 말하는 문장, 진행 상태를 말하는 문장, 자료를 주어로 삼는 문장, 내용 없는 수식. 고치지 않고 지움
- 변경 범위: bizplan-artifact-format — references/06-content-rules.md(신설), SKILL.md(「본문 내용」 절), references/01-format-rules.md(겉모양만 다룬다는 경계와 링크), 04-content-authoring.md(문법만 다룬다는 경계와 링크). 기존 요구사항 ID·기능 의미, 계약·고객의 필수 목차와 기재 의무, 코드·약어의 의미, 식별 체계 구분은 보존 대상으로 따로 적음
- 제외 범위: 기계 검사를 넣지 않음. 내용 검토는 사용자가 함. 금지어 자동 삭제 없음. 기존 산출물 본문은 수정하지 않음. 스크립트·서식값·출력 HWPX 변경 없음. `bizplan-hwpx/references/14-general-artifact-content-quality.md` 는 미확정·결정 필요를 본문에 보존하고 독자의 판단을 기준으로 삼으므로 기준이 다름. 공용 원본으로 합치지 않고 그대로 둠
