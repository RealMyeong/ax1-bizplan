# 산출물 서식: 생성 단계에서 그림 삽입, 그림 검사 4종

- 사용자 효과: ① 본문 마크다운에 `[[그림: images/개념도.png | 120mm | [그림 1-1] 개념도]]` 를 적으면 생성 단계가 그림을 문서 안에 넣음. 사후 치환 단계가 없으므로 본문을 고쳐 다시 생성해도 그림이 사라지지 않음 ② 표준 마크다운 그림 문법(`!` + 대괄호 캡션 + 괄호 경로)도 같은 뜻으로 읽음. 종전에는 `strip_inline` 이 지워 그림이 조용히 사라졌음 ③ 폭 기본값 140mm, `120mm`·`120x70mm` 로 지정, 본문 폭을 넘으면 본문 폭으로 줄이고 경고. 높이 생략 시 원본 비율 ④ 그림 파일이 없거나 지원하지 않는 형식이면 문서를 만들지 않고 중단함 ⑤ 그림은 가운데 정렬·글자처럼 취급으로 들어가고, 캡션은 그림 바로 아래 문단이 되어 기존 캡션 규칙(`[그림 1-1] 제목`, 10pt 가운데, 위 3pt/아래 10pt, 본문 참조 필수)을 그대로 적용받음 ⑥ check 가 그림 캡션 위치(그림 바로 아래), 본문 폭 초과, 글자처럼 취급, 매니페스트 등록 누락을 위반으로 보고함
- 변경 범위: bizplan-artifact-format — hwpx_format.py(그림 상수·자리표시 파싱·그림 머리글 픽셀 판독·`add_bin_data`·그림 문단 판정), build_artifact.py(`pic` 블록 파싱·`Emitter.picture`·`prepare_pictures`·`--image-dir`), check_artifact_format.py(4-6 그림 검사), SKILL.md, references/01-format-rules.md(그림 절), 04-content-authoring.md(그림 절). 그림 등록은 한/글이 쓴 문서와 같은 형태로 `Contents/content.hpf` 의 `opf:item` 에만 하며(이 양식의 header.xml 에는 binDataList 가 없음) `isEmbeded="1"` 이 없으면 한/글이 그림을 버림. `BinData/*` 는 무압축으로 기록. 그림 문단의 줄 배치 캐시는 표 문단과 같이 본문 10pt 기준이며, 그림 높이로 잡으면 줄간격 160% 가 그림 높이의 60% 만큼 빈 자리를 덧붙임
- 제외 범위: 표준 라이브러리만 사용하며 외부 패키지 의존성을 추가하지 않음. 캡션 번호 자동 생성 없음(사람이 `[그림 1-1]` 까지 적고 형식이 어긋나면 경고). 표 안 그림, 어울림(글자 옆 흐름) 배치, 그림 교체 없음. 그림 위치·크기·쪽 넘김의 자동 판정 없음
- 검증: 두 문법을 모두 쓴 익명 샘플 생성 → `BinData/image2.png`·`image3.png` 무압축 기록과 매니페스트 등록 확인, 100mm 지정이 `hp:sz width="28346"`·원본 비율 높이 24mm 로 들어감, 캡션 문단모양 `align=CENTER prev=300 next=1000` 확인, 폭 400mm 지정은 본문 폭 150mm 로 줄이고 경고, check 위반 0건. 미참조 그림 캡션 샘플은 `캡션 참조` 위반으로 보고. `python scripts/skill_contract_test.py` 4건 통과. 한컴 시각 검증 대기
- 호환성: 기존 마크다운에는 그림 자리표시가 없으므로 출력이 달라지지 않음. 본문에 `![...](...)` 를 쓰던 문서는 종전에 그림이 사라졌고 이제 그림으로 들어감. 생성·적용 흐름과 기존 옵션은 종전과 같음
