# 산출물 서식: 절 간격 축소·불릿 통일·개정 이력 자동 기록·파일명 버전 연동

- 사용자 효과: ① 장 제목 바로 다음의 절 제목은 위 간격이 14pt→8pt 로 줄어 장→절 전환이 덜 벌어짐(그 외 절은 종전 14pt). ② 1수준 불릿 기호가 큰 동그라미 `●` 에서 `•`(U+2022) 로 바뀜 — 단계별 기호는 `•` `-` `·` `·` 이고 소급 적용 때 1수준 `●` 만 `•` 로 교체함. ③ 개정 이력표에 오늘 날짜와 버전을 자동 기입함 — 비어 있으면 v0.1, 있으면 마지막 버전을 한 단계 올려(v0.2→v0.3) 다음 빈 행에, 빈 행이 없으면 마지막 행을 복제해 행을 추가(서식·칸 구조는 양식 그대로, rowCnt·표 높이 갱신). 같은 날 같은 개정내역이면 다시 쓰지 않아 멱등임. ④ 출력 파일 이름의 버전 조각(`_v0.x`)을 개정 이력 최신 버전과 동일하게 맞춤(조각이 없으면 덧붙임, 꼬리표 보존). apply 는 `--rev-note`/`--rev-author`/`--no-revision` 을 받고 기본 출력 이름이 `<이름>_fmt.hwpx` 에서 `<이름>_v0.x.hwpx` 로 바뀜. check 가 개정 이력 존재·버전 형식·파일명 일치를 함께 검사함
- 변경 범위: bizplan-artifact-format — SKILL.md, references/01-format-rules.md, 03-front-matter-lock.md(개정 이력 기입 예외), 04-content-authoring.md, scripts/hwpx_format.py(개정 이력 도우미 신설), apply_artifact_format.py(argparse 전환 포함), build_artifact.py, check_artifact_format.py
- 제외 범위: 문서 정보표(버전·발행일·상태)의 자동 기입 없음. 개정 이력 확인자 칸은 기입하지 않음. `◦`(U+25E6) 대체 문자 미정의는 종전대로
- 검증: 샘플 생성 → check 위반 0·XML 적합·장 직후 절 prev=800/그 외 1400·불릿 단계별 `•` `-` `·` `·`·개정 v0.1 기입·파일명 자동 `_v0.1`. apply 연쇄 v0.2~v0.5(작성자 기입, 빈 행 소진 시 행 추가 rowCnt 5→6·표 높이 +2697) 모두 check 통과. 같은 날 같은 내역 재적용은 행이 늘지 않고 이름이 같으면 .bak 백업 후 저장. 옛 커밋 스크립트로 만든 옛 기호 문서 소급 변환(1수준 `●`→`•` 1개 교체·절 간격 2건 수정) 후 check 통과. 목차 없는 문서는 종전대로 중단하며 개정 기록도 하지 않음. `python scripts/build_release.py` 통과. 한컴 시각 검증 대기
- 호환성: 기본 실행만으로 개정 이력이 기록되고 출력 이름이 바뀌므로 종전 `_fmt` 이름을 기대하는 흐름은 `--no-revision` 을 쓰면 종전과 같음. 옛 기호 문서는 apply 실행 시 새 규칙으로 소급 변환됨. check 는 개정 이력이 비었거나 파일명 버전이 다르면 새로 위반으로 보고함
