# AX1 발표자료 제작 스킬 추가

- 사용자 효과: 발표 목적·청중·시간을 바탕으로 스토리보드와 시각 방향을 먼저 확정하고, 편집 가능한 네이티브 PPTX 또는 전체 슬라이드 이미지형 PPTX를 발표자 노트와 함께 생성·전수 검증할 수 있음
- 변경 범위: `ax1-presentation` 스킬·참조·템플릿·로컬 조립/검사 스크립트, 공통 정책 동기화, 설치 안내, upstream 검토 기록과 자동 수용 테스트
- 제외 범위: 외부 이미지 API·API 키 저장, 런타임 자동 설치, upstream 바이너리 스타일 자산·예제 문서와 저장소 이름 변경
- 검증: 새 스킬 빠른 검증, 이미지형 PPTX 생성·한글 노트·재개방·번호 누락·덮어쓰기 거부 수용 테스트와 전체 저장소 빌드 수행
- 호환성: 기존 7개 `bizplan-*` 스킬의 이름·호출·동작은 유지하며 전체 설치 묶음에 여덟 번째 독립 스킬과 두 Python 패키지 요구사항이 추가됨
