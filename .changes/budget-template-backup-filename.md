# 공통 사업비 양식·스킬 백업·파일명 규칙 보완

- 사용자 효과: 스킬 업데이트 성공·검증 후 직전 설치본 백업 한 묶음만 보관. `ax1-budget`으로 공통 XLSX 사업비·구매비용 관리대장을 선택해 작성·갱신. 용어사전 2026-09-03/v0.3에 맞춰 신규 사업비 BUD, 문서 버전 의미와 기존 이름 전환 기준 보완.
- 변경 범위: 새 `ax1-budget` 스킬·공통화한 양식·무결성 검사, 모든 스킬의 공통 백업 정책과 산출물 파일명 정책 복사본, 빌드·회귀검사, README·팀원·배포자·HTML·로드맵 안내.
- 제외 범위: 원본 XLSX·내부 DOCX 수정 또는 배포, 기존 대시보드 계산 구조 개선, HWPX 엔진·upstream 변경, 실제 백업 삭제, 설치본 갱신, 커밋·푸시·릴리즈.
- 양식 검토: 사용자 제공 원본 SHA-256은 템플릿 명세에 기록. 빈 거래·승인예산을 확인하고 특정 참여기관·프로젝트·과거 관리번호를 공통화. 원본 4개 시트, 2032개 수식, 표 2개, 차트 1개, 셀서식·병합·입력규칙 보존 비교. 새 양식 SHA-256과 배포 근거는 `skills/ax1-budget/assets/templates/template-manifest.json` 참조.
- 검증: `python scripts/build_release.py` 통과(HWPX·발표자료 회귀 포함), `python scripts/budget_acceptance_test.py` 6개 검사 및 통합·개별 ZIP 격리 검증 통과. `quick_validate.py` 9개 스킬 통과. `scripts/budget_formula_acceptance.mjs`로 합성 입력 16개 계산 주장 통과. 공통화 전후 대시보드·코드표 렌더 확인 및 XLSX readback 확인.
- 재현: 수식 테스트는 제공된 `@oai/artifact-tool` 런타임에 접근 가능한 임시 작업폴더에 스크립트를 복사한 뒤 `node budget_formula_acceptance.mjs <절대경로/ax1-budget-ledger.xlsx>` 실행. 테스트는 메모리에서만 합성값을 바꾸며 원본을 저장하지 않음. 기본 빌드의 빈 양식·패키지 검사는 표준 라이브러리만 사용.
- 제한: 실제 Excel 개방·상호작용·인쇄 검증은 하지 않음. 프리뷰 도구는 이미지 생성 뒤 프로세스 종료코드 1을 반환했으나 생성된 변경 전후 이미지 자체는 확인함. 원래 통합현황 비목별 표·차트는 5개 비목만 표시하므로 다른 비목 사용 시 별도 보완 필요. 백업 정책은 에이전트 지침이며 이번 변경은 자동 삭제 프로그램이나 설치 실행이 아님.
- 호환성: 기존 8개 호출·공통 확인·산출물 이력 정책 보존. 신규 스킬만 초기 metadata 0.1.0이며 기존 버전은 유지. 현재 안정 v0.9.4와 차기 작업본을 구분해 안내. 새 독립 스킬 추가의 최종 팩 버전은 관리자가 릴리즈 때 결정.
