# 일반 산출물 본문 품질 검토

- 사용자 효과: 작성 지침·대화 과정의 본문 혼입을 검토하고 근거·한계는 보존함. 일반 산출물을 사업계획서 전용 흐름으로 잘못 보내지 않음.
- 변경 범위: bizplan-hwpx의 역할·준비·검증 참조, 일반 산출물 본문 품질 참조, 안내문·합성 사례·개별 ZIP 포함 검사.
- 제외 범위: 생성 엔진·템플릿·upstream, 다른 스킬의 작성 규칙, 자동 의미 판정기·금지어 삭제, 원래 사용자 문서의 재작성.
- 검증: 합성 6사례 수동 검토와 합성 Markdown 생성·문자 readback, 스킬 구조 및 기존 전체 빌드·격리 검사. 독립 새 세션 행동 검증과 한컴 시각 검증은 미수행.
- 호환성: 호출 방식과 서식 유지. 출처·인용·한계·필수 승인 이력을 문맥 없이 제거하지 않음. 서식만 요청한 작업은 내용 개작하지 않음.
