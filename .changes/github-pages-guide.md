# GitHub Pages 사용 설명서

- 사용자 효과: 기존 HTML 안내문을 다운로드하거나 소스코드로 열지 않고 고정 웹 주소에서 바로 읽고 팀원과 공유함. 최신 안정 릴리즈 기준으로 자동 갱신함.
- 변경 범위: Pages 배포 워크플로·안내문 전용 패키징·회귀 테스트, README·팀원·배포자 안내 링크. 상단 버전·날짜와 하단 원문 링크는 웹 배포 시 자동 처리함.
- 제외 범위: 스킬 기능·metadata·팩 버전·태그·기존 Release 자산·설치본 변경, 별도 호스팅 서비스, 실제 사업자료 공개, 기존 안내문 디자인 재작성.
- 검증: 공개 파일 3개 허용 목록, 한글·원문 보존, 버전·커밋·날짜·출처 해시, 상대경로·외부 자산·누락 앵커 차단, 탭·복사 기능과 CSS 원문 보존, 출력 무덮어쓰기 회귀. 전체 빌드와 실제 Pages 배포·웹 접속을 확인함.
- 호환성: 기존 HTML 파일 경로와 다운로드 이용 방식 유지. main의 미릴리즈 본문은 웹 안내로 배포하지 않음. 기존 자동 릴리즈의 GITHUB_TOKEN 이벤트 제한을 고려해 성공한 워크플로 완료 후 배포하며 PR/Fork 입력은 제외함.
