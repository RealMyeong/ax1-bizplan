# HWPX 사용자 접근과 문서 관리

- 배포 연결: 초기 로컬 패치를 지침 정리와 함께 v0.10.2 / bizplan-hwpx v0.4.7 배포 묶음에 포함함. 아래 범위는 초기 개발 당시 기록임.
- 사용자 효과: Windows 최종 파일이 임시 파일 ACL을 그대로 물려받는 하드링크 게시를 피하고 실제 사용자 접근을 확인함. 표지 제목·문서유형 중복 표시를 줄이고 문서 정보 질문·입력과 기준본 개정 이력 누적을 지원함.
- 변경 범위: bizplan-hwpx v0.4.6 로컬 미배포 패치, 생성기·게시 함수·문서 정보/이력 모듈·권한 진단·검사기·참조·합성 회귀.
- 제외 범위: 승인 템플릿 원본, 실제 사용자 문서, 다른 스킬·upstream 플러그인, 스킬팩 VERSION·태그·푸시·릴리즈 변경 없음.
- 검증: 변경 전 8개 재현 시험 실패 확인 후 통과. 전체 빌드·구조·배포 ZIP 격리·실제 사용자 컨텍스트 접근 검사를 수행하며 상세 결과와 미검증 범위를 검증 기록에 남김.
- 호환성: 개정은 기준본·SHA-256 입력이 필요함. 이력이 없다고 초기화하지 않으며 개명·다른 산출물군·용량 초과는 별도 확인/확장 검증 필요. Windows 복사 완료 전에는 후보를 열지 않음.
