# HWPX 제목 간격과 목록 hanging indent

- 사용자 효과: 본문·목록·표 뒤의 수준 2~4 제목에 안정적인 6pt 윗간격이 생기고, 긴 글머리표의 둘째 줄 이후가 첫 줄 본문 시작 위치에 맞춰짐
- 변경 범위: `bizplan-hwpx` 경량 생성·서식·검사 규칙, 합성 HWPX 회귀 테스트와 관련 관리자 문서
- 제외 범위: 승인 템플릿, 사용자 PI-LAM 문서, upstream HWPX 플러그인, 다른 사업계획서 스킬, 통합팩 버전·태그·Release
- 검증: 실제 검토본 SHA-256 대조와 `#0000FF` 런 위치 확인, 합성 본문 회귀 테스트, `check_headless_artifact.py`, `quick_validate.py`, 전체 빌드 및 가능한 범위의 프리뷰·한컴 검증
- 호환성: 숫자 제목 0·3·5·7개 공백, 최대 4단계, 한글 원문, 160% 줄간격, 파일명·버전·개정이력·표 머리행 규칙은 유지함. HWPX 본문 목록만 기존 앞 공백 9개에서 문단 hanging indent로 전환됨
