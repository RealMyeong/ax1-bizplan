# HWPX 그림·캡션 선별 통합과 긴 표 제목행 반복

- 사용자 효과: PR #7의 독립 그림 삽입·하단 캡션 기능을 기존 `bizplan-hwpx`에 통합한다. 한 쪽을 넘는 표는 첫 행 전체를 제목행으로 지정하고 제목행 자동 반복을 켠다. 짧은 표의 글자처럼 취급, 긴 표의 해제/CELL, 기존 정렬·160%·3단계 제목·12pt 경계를 유지한다.
- 선별 범위: 로컬 PNG/JPEG 그림 임베드, 표·그림 캡션·순번·참조 검사, 작성 지침과 독자용 본문 분리 원칙의 유지. PNG/JPEG 바이트·매니페스트·실제 BinData 검증을 추가한다.
- 변경 범위: bizplan-hwpx 지침·참조·생성·검사·배치, 그림 리소스 보조 모듈, 합성 회귀, 빌드의 회귀 실행·필수 ZIP 모듈 검사. 상세 결과는 `docs/verification/hwpx-pr7-selective-integration.md`에 기록한다.
- 미반영: 중복 `bizplan-artifact-format` 스킬·새 표지 3개·4단계 제목·자동 기호 치환·기존 출력 덮어쓰기·이력 초기화·배경/미확정 사항 일괄 삭제·검증 우회. 기존 승인 템플릿과 해시를 변경하지 않는다.
- 검증: 수정 전 제목행 반복 3개 회귀 실패를 확인했다. 수정 후 표 흐름 18개, 그림·캡션 13개, 문서 정보 9개와 기존 HWPX 인수 테스트를 실행한다. 새 그림 회귀도 전체 빌드가 실행하고 배포 ZIP의 필수 모듈을 확인한다. 합성 입력만 사용한다.
- 호환성: 새 생성·재생성에 적용된다. 기존 문서를 자동 수정하지 않는다. 캡션 번호는 자동 재번호하지 않는다. 지원 밖 그림은 삭제/추정하지 않고 중단한다. 스킬 metadata는 0.4.8이며 사용자 승인에 따라 통합 팩 v0.10.3으로 배포한다. 설치본은 별도 업데이트 요청 전까지 변경하지 않는다.
- 실제 한컴: 2026-10-01 한컴오피스 2024(13.0.0.4049)에서 합성 10쪽 전체 관찰 통과. 긴 표의 두 후속 페이지에서 첫 행 전체 반복, PNG/JPEG 색상 표시와 같은 쪽 하단 캡션, 기존 12pt 경계·목록 들여쓰기·새 장 시작·상태 기호를 확인하고 화면 증거를 저장소 밖에 보관한다. 저장 없이 닫은 후 대상 SHA-256 불변을 확인한다.
- 제한: JPEG 자동 검사는 마커 구조·크기 검사이며 임의 JPEG 전체 디코딩 보장이 아니다. 이번 합성 문서의 전체 페이지 관찰을 모든 입력·쪽 경계 조합의 보장이나 자동 렌더 영수증으로 표현하지 않는다.
