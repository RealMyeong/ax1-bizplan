# AX1 HWPX 개정 이력·파일명 버전 동기화

- 사용자 효과: 승인 AX1 템플릿으로 새 일반 산출물을 만들 때 확정 버전·개정일자·개정내역과 선택 작성자를 개정 이력표에 기록하고 파일명 끝의 단일 버전 접미사와 일치시킴. 버전 충돌·복수 토큰·손상된 개정행·기존 출력은 파일을 쓰기 전에 거부함
- 변경 범위: `bizplan-hwpx` 경량 HWPX 공용 모듈·생성기·검사기·수용 테스트, 서식·템플릿 경계·생성·검증·산출물 버전 정책, 팀원·배포자 안내
- 제외 범위: 공식 사업계획서 또는 임의 HWPX의 개정표 자동 수정, 버전 자동 증가, 확인자 자동 입력, 개정행 자동 복제, 원본·기존 출력 덮어쓰기, PR #4의 별도 `bizplan-artifact-format` 스킬·H2 간격 변경·원본 자산 반입
- 검증: 표준 라이브러리 수용 테스트에서 정상 v0.1 생성, 한글·백슬래시 개정내역, 부분·중복·역순·포화·선언 범위 밖 개정행, AX1 표지 시그니처 손상, 파일명 불일치·복수·난수 유사 토큰, 기존 대상 무덮어쓰기와 기존 4단계·160%·의미 기호·한글 원문 회귀 검증 통과. Python 구문 검사, 전체 빌드, 개별 ZIP 격리 생성·검사·readback과 `git diff --check` 통과. 한컴 시각 검증은 대기
- 호환성: 기존 `bizplan-hwpx`와 승인 템플릿을 유지하며 새 일반 산출물 경량 경로에만 fail-closed 검사를 추가함. 기존 자동 생성 호출은 버전과 일치하는 출력 이름·개정 정보를 제공해야 함
