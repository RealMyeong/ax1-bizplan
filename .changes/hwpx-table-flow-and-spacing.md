# HWPX 표 흐름·경계 여백·번호 목록 보정

- 사용자 효과: 짧은 표는 글자처럼 취급, 최종 계산 높이가 한 쪽을 넘는 표만 해제 + 셀 단위 나눔. 표↔본문·목록·제목·표의 12pt 경계를 한 번만 확보한다. 번호 목록도 후속 줄이 첫 줄 본문 위치에 맞는다.
- 원인: 이전 생성기는 모든 표를 floating으로 고정하고 제목 앞에만 간격을 지정했다. 번호 목록은 일반 본문으로 파싱했으며, 열 폭 재배분 후 셀 줄 수·행 높이·앵커 캐시를 동기화하지 않았다.
- 구현: 최종 폭 기반 셀 재배치 → 한 쪽 높이 비교 → inline/floating 분기 → 경계 단일 여백 → 앵커 캐시 갱신. 한 셀 자체가 한 쪽을 초과하면 출력 전에 중단한다.
- 검증: 합성 회귀에서 수정 전 3개 실패(짧은 표 모드·표 경계 간격·번호 목록 들여쓰기)를 확인했다. 수정 후 전용 회귀 및 기존 인수 테스트를 실행한다. 실제 문서·승인 템플릿 사본은 테스트 자산에 포함하지 않는다. 상세 증거는 `docs/verification/hwpx-table-layout.md` 참조.
- 호환성: 승인 AX1 경량 생성물만 대상. 기존 사용자 문서·공식 양식·upstream 플러그인·다른 스킬을 자동 수정하지 않는다. 표지~목차 제목, 160%, 개요 3단계, 축 셀 맞춤, 한글·개정 이력·파일명 정책 유지. 기존 생성물을 재생성하면 페이지 수와 표 위치가 달라질 수 있으므로 산출물 버전 규칙을 따른다.
- 제한: 쪽 높이 판정은 메트릭 추정이다. 경계 사례와 최종 페이지 나눔은 실제 한컴 확인이 필요하다. 릴리즈·설치 버전 변경과 배포는 별도 승인 범위다.
- 변경 범위: bizplan-hwpx 지침·생성·서식·검사 로직, 합성 회귀 테스트, 검증 기록, 활용 예시 1개와 정확한 경로·SHA-256 기반 빌드/PR 허용 검사.
- 제외 범위: 실제 업무 문서, 승인 템플릿 원본, 다른 스킬과 upstream 플러그인, 새 릴리즈·설치본 업데이트.
- 기여자: AX1 관리자 요청, Codex 구현·검증.
- 활용 예시: 사용자가 확인한 비식별 합성 HWPX 1개를 `examples/hwpx/DXS-AX-TST-표흐름_합성검증-20260907-v0.1.hwpx`에 포함한다. 실제 업무 문서나 템플릿 원본 사본이 아닌 생성 결과이며, 별도 예시 Markdown·안내문은 추가하지 않는다. SHA-256: `8740253BF457F89FBBAB9592A2712F4F0AACD71B2E07CBE546F120A2C3313880`.
