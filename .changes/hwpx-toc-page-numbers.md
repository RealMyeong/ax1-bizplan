# 경량 HWPX 목차를 한/글 차례 구조로, 본문 쪽 번호 추가

- 사용자 효과: 경량 생성 산출물의 목차가 장·절을 모두 담은 한/글 차례 구조(차례 필드, 제목 하이퍼링크, 오른쪽 점선, 쪽 번호)로 만들어져 한컴에서 「차례 새로 고침」과 제목 이동이 됨. 장은 14pt 굵게, 절은 12pt로 구분되고, 본문에는 1장부터 아래 가운데 `- 1 -` 쪽 번호가 찍힘(표지·목차는 번호 없음)
- 변경 범위: `bizplan-hwpx`의 `headless_hwpx.py`(차례 구조·쪽 번호 도우미, 허용 글자 크기 14pt), `build_headless_artifact.py`(장·절 목차 생성, 1장 쪽 번호, 서식 적용 뒤 목차 쪽 번호 추정), `layout_headless_artifact.py`(쪽 번호 추정: inline 표 통째·floating 표 행 단위·제목 줄 반복 높이), `check_headless_artifact.py`(차례 필드·제목 일치·글자 크기·링크·쪽 번호·본문 쪽 번호 검사), 선택 도구 `toc_pages_hwp.py`, 참조 08·09·11과 SKILL.md, 회귀 테스트 `scripts/headless_toc_test.py`
- 제외 범위: 항(3단계) 이하 목차, 쪽 번호 서식 선택(위치·모양 고정), 경량 경로 안의 한컴 실행. 한컴 PDF 기반 쪽 번호 보정은 선택 도구로만 제공하며 CI·빌드는 실행하지 않음
- 검증: `scripts/headless_toc_test.py` 12건, 기존 경량 수용·표 흐름·메타데이터·그림 테스트, `python scripts/build_release.py` 통과. 합성 문서를 한컴 2024 COM으로 PDF 변환해 목차 점선·쪽 번호·링크 문단·본문 쪽 번호 표시와 추정 쪽 번호(장·절 6개 모두 실제 쪽과 일치)를 확인
- 호환성: 기존 호출·인자 그대로. `--no-toc`도 그대로이며 이때도 본문 쪽 번호는 넣음. 목차 쪽 번호는 글꼴 메트릭 추정이므로 제출 후보는 한컴 전 페이지 관찰 때 실제 쪽과 대조
