# 본문 개요 수준과 앞 공백 표준화

- 사용자 효과: 공식 양식에 별도 지정이 없을 때 본문을 `1. / 1.1 / 1.1.1 / •`로 작성하고 수준별 앞 공백을 일반 반각 공백 0·3·5·7개로 일관되게 유지함
- 변경 범위: `bizplan-draft` 작성 규칙, `bizplan-hwpx` 경량 생성 지침·생성기·검사기·수용 테스트
- 제외 범위: 별도 개요 체계를 지정한 공식 양식, 바이너리 HWP 편집, 기존 문서의 임의 재서식
- 검증: 제목 3단계와 본문 목록의 XML·readback 앞 공백, 4단계 제목의 목록 전환, 문단 왼쪽 들여쓰기 중복 금지와 결함 탐지
- 호환성: 공식 양식 우선 원칙과 기존 Markdown `#`·`##`·`###` 입력은 유지하며 경량 생성 결과의 기본 들여쓰기만 표준화함
