# AX1 스킬 지침 정리 (로컬 미배포)

- 배포 연결: 2026-09-14 사용자 승인으로 v0.10.2 배포 묶음에 포함함. 아래 범위는 최초 로컬 개선·설치 당시 기록임.
- 사용자 효과: 9개 스킬의 핵심 진입 지침을 압축하고 요청별 적용 범위·참조 경로·완료 기준을 명확히 함. 일반 작성 요령과 반복 보고를 줄이고 같은 요청의 확인을 재사용함.
- 보존: 최초 별도 메시지 동의, 사업 브리프·이미지 샘플 승인, 공식·고객 양식 우선, 원본 보호, 파일명·버전·최신본 연동, 한글·HWPX 서식·검증·접근·개정 이력, 스킬 자동 발견.
- 충돌 정리: 공통 문서의 오래된 4단계 제목을 승인된 3단계 기본값으로 맞춤. 새 AX1 일반 HWPX 경로에 upstream 설치를 일괄 강제하던 공통 지침을 수정함.
- 호환성: 기존 9개 스킬 이름·폴더·실행 스크립트·승인 자산 유지. 새 공통 참조를 각 스킬에 포함해 개별 설치와 Codex·Claude 사용 유지. 특정 모델/API를 하드코딩하지 않음.
- 검증: 전체 빌드, 참조·동기화 검사, 기존 HWPX·PPTX·예산 테스트, 독립 에이전트의 대표 요청 판단을 수행하고 검증 기록에 결과·제한을 남김.
- 범위 밖: API·앱 모델 변경, 실제 사용자 문서 수정, 원격 쓰기, 커밋·푸시·스킬팩 버전·태그·릴리즈 없음.
