# 웹 안내 왼쪽 목차

- 사용자 효과: 웹 안내의 왼쪽 목차에서 원하는 설명으로 이동하고 현재 위치를 확인함. 좁은 화면에서는 접는 목차로 이용함.
- 변경 범위: 웹 배포 도구의 UI 전용 CSS·JavaScript와 주입·무결성 검사. 목차에서 다른 대상의 항목을 선택하면 해당 탭을 함께 전환함.
- 제외 범위: 릴리즈 본문·스킬·버전·설치본·기존 Release 변경 없음.
- 검증: Pages 패키징·원문 CSS/JS 보존·공개 파일 허용 목록·UI 자산 해시, 전체 빌드 및 브라우저의 목차 이동·탭·복사·반응형 확인.
- 호환성: 본문은 안정 Release에서만 읽고 신뢰된 main의 UI만 추가하므로 별도 스킬 릴리즈 없이 웹 사용성만 배포 가능함. 원본 다운로드 HTML은 기존 형태 유지.
