HWPX 사용자 선행 설치

DOCX만 사용할 때는 건너뜁니다. HWPX 양식 작성·수정이 필요하면 AX1이 검증한 upstream 플러그인을 한 번 설치하고 앱을 다시 시작합니다.

AX1 검증 upstream HWPX 플러그인을 사용자 범위에 설치해줘.

원본: https://github.com/airmang/hwpx-plugins
AX1 검증 ref: b7ab90a1db826c5fa5db024ad01dc5132d073953
1. Windows에서 uv와 uvx가 실행되는지 확인해줘.
2. 위 ref로 hwpx 마켓플레이스를 고정하고 hwpx-plugin을 설치해줘.
3. core, automation, plugin 버전을 확인해줘.
4. 설치 후 앱 재시작과 새 작업이 필요하면 알려줘.
AX1 검증 기준: source ref b7ab90a1db826c5fa5db024ad01dc5132d073953 · python-hwpx 6.2.1 · python-hwpx-automation 7.0.2 · hwpx-plugin 2.0.1

프로젝트 준비

$bizplan-prepare를 사용해서 현재 프로젝트 폴더를 사업계획서 작성 작업공간으로 준비해줘. 기존 파일은 이동하거나 덮어쓰지 마.

초안 작성

$bizplan-draft를 사용해 공고문·RFP·양식을 먼저 분석해줘. 바로 큰 틀만 쓰지 말고 아이디어와 구현 방식이 부족하면 먼저 질문해줘. 내 답변을 과업, 연차, KPI, 실증, 사업화 구조로 다듬은 뒤 DOCX 초안을 작성해줘.

HWPX 양식 반영

$bizplan-hwpx를 사용해서 확정된 문안을 공식 HWPX 양식에 반영해줘. 원본은 덮어쓰지 말고, 양식 위치를 확인한 뒤 dry-run과 실제 반영을 구분해줘. 구조·본문·표 readback, 페이지 프리뷰와 한컴 전체 페이지 확인 결과도 알려줘.

검토 → 수정 → 제출점검

  • bizplan-review로 치명적 누락과 논리·수치 불일치 확인
  • bizplan-revise로 목표·KPI·연차·역할·표를 함께 수정
  • bizplan-preflight로 제출 직전 상태 확인
  • 마지막 제출은 담당자가 공식 자료와 대조 후 승인

업데이트 요청문

AX1 Bizplan을 최신 안정 버전으로 업데이트해줘. 기존 버전을 백업하고 7개 스킬을 함께 교체한 뒤 업데이트 전후 버전, 변경된 스킬과 검증 결과를 알려줘. HWPX 플러그인을 사용하면 upstream 버전과 건강검사도 확인해줘.
개선 요청: 사용한 에이전트·스킬·버전, 실제 결과, 기대 결과와 사람이 보완한 내용을 개선 요청 Form에 적습니다.
입력 금지: 실제 사업계획서 내용, 기관명, 개인정보, 미공개 RFP·평가의견과 계정정보는 Form이나 GitHub에 직접 입력하지 않습니다.

Release Pipeline

수정·검증·릴리스

1. 작업 브랜치

git switch main
git pull --ff-only
git switch -c fix/간단한-작업명

신규 근거를 반영할 때는 bizplan-evidence-update로 단일 사례 편향과 기존 규칙 충돌을 먼저 확인합니다.

2. 버전 결정

변경버전
오류·호환되는 소규모 개선패치
새 기능·워크플로·스킬마이너
설치·사용법 호환성 단절메이저

VERSION, 플러그인 버전, 변경 스킬 버전과 CHANGELOG.md를 함께 맞춥니다.

3. 검증·패키징

python scripts/build_release.py
git status --short
git diff --check
git diff

전체 ZIP, 7개 개별 스킬 ZIP, 체크섬과 저장 금지 자료 포함 여부를 확인합니다. HWPX 변경이면 익명화 샘플의 dry-run·readback·프리뷰·Windows 한컴 전체 페이지 관찰까지 수행합니다.

4. 태그·자동 Release

git switch main
git pull --ff-only
git tag vX.Y.Z
git push origin main
git push origin vX.Y.Z

태그는 VERSION 앞에 v를 붙인 값과 같아야 합니다.

GitHub Issue 전환 기준

  • 버전과 대상 스킬이 식별됨

  • 범용 규칙 또는 사업 프로파일로 분리 가능함
  • 기관명·개인정보·미공개 원문이 제거됨
