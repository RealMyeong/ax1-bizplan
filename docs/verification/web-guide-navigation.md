# 웹 안내 목차 검증

2026-09-09, 안내 본문 기준 v0.10.1. 스킬·설치본·Release는 변경하지 않는다.

## 배포 구분

본문과 기존 CSS·탭·복사 스크립트는 안정 릴리즈 원문을 그대로 사용한다. 신뢰된 main의 `scripts/web/guide-navigation.css`와 `.js`만 웹 배포 단계에서 인라인으로 추가한다. 따라서 스킬 릴리즈 없이 목차 UI만 배포할 수 있으며, main의 미릴리즈 안내 내용은 공개하지 않는다. `version.json`은 본문 커밋·원문 해시 외에 목차 CSS/JS 해시도 기록한다. 원본 다운로드 HTML에는 웹 전용 목차가 추가되지 않는다.

## 확인 결과

- Pages 자동 검사 8건: 공개 파일 3개 제한, 안정 버전·출처, 원본 불변, 기존 CSS/JS 보존, 목차 자산 1회 삽입·해시 일치 등 통과.
- 전체 저장소 빌드와 기존 스킬·패키징 회귀 통과.
- 브라우저 1280px: 왼쪽 고정 목차, 업데이트 요청문 이동, 현재 위치 표시, 숨겨진 배포자 탭의 팀 공지문 이동, 뒤로가기로 팀원 항목 복원 확인.
- 브라우저 390px: 기본 접힘, 목차 열기·항목 선택 후 자동 접힘, 탭 자동 전환 확인. 긴 카드·인라인 코드의 가로 넘침을 보완한 뒤 페이지 폭 초과 없음 확인.
- 기존 복사 버튼의 `복사됨` 성공 상태 및 JavaScript 오류 없음 확인.
- 2열에서 같은 높이에 있는 제목끼리 현재 항목 표시가 바뀌지 않도록 선택된 항목을 유지하며, 제목은 상단 탭 아래 약 90px에 위치함.

목차는 h2/h3에서 생성한다. 링크를 직접 열거나 뒤로가기로 돌아와도 해당 탭을 활성화한다. 좁은 화면에서는 하단 고정 접이식 목차를 사용한다. 키보드 링크·summary 기본 동작, 현재 항목 `aria-current`, 이동한 제목 포커스와 모션 감소 환경을 지원한다. 별도 스크린리더·실제 모바일 기기 시험은 미수행이다.
