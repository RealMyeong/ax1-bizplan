# 일반 산출물 내용 검토 합성 사례

실제 사업자료가 아닌 수동 수용 검토용 사례다. 문자 패턴 일치만으로 의미 품질 통과를 자동 판정하지 않는다. 공통 최초 이해 확인 뒤 사용자가 별도 동의했다고 가정한다.

## 1. 작성 지침 혼입과 근거 연결

입력: 가상 조립라인의 공정은 A~C이다. 설비 EQ-01의 상태 신호 대응관계는 미정이다. 기존 요구사항 R-01은 설비별 상태 집계이다.

후보: “제공자료에는 공정 A~C가 기재되어 있다. 자료를 임의로 채우지 않는다. 문서 작성 동의는 고객 승인을 의미하지 않는다. R-01: 설비별 상태 집계.”

판정: 내용 수정 필요. 공정 사실은 업무 대상 중심으로 고치고 출처를 남긴다. 두 작업 규칙은 본문에서 분리한다. 매핑 미정과 R-01 구현의 의존관계를 연결하되 승인·새 제어 기능을 만들지 않는다. 가능한 수정 결과는 `general-artifact-reviewed-sample.md`를 참조한다.

## 2. 불확실성과 인용 예외

입력: 면담 메모는 “가동률 하락은 센서 누락 때문일 가능성이 있다”고 한다. 계약은 분석 근거·한계·검토 이력을 필수로 요구한다.

후보: “센서 누락이 가동률 하락의 원인이다.”

판정: 근거보다 강한 단정이므로 보류. 원인 가능성으로 되돌리고 추가 확인 필요와 면담 출처를 남긴다. 필수 한계·검토 이력을 삭제하지 않는다. 단순 `자료`·`승인` 단어 검출로 처리하면 실패다.

## 3. 식별자 역할과 미정 구조

입력: R-01은 요구사항 ID, EQ-01은 설비 ID, DB10.DBX0.0은 신호 주소의 가상 예시다. 실제 대응관계와 QX 약어의 풀이는 제공되지 않았다.

후보: “R-01과 EQ-01은 동일 장비를 뜻하며 QX는 품질지수를 뜻한다.”

판정: 근거 없는 관계·풀이는 제거하고 각각의 알려진 역할을 설명한다. 주소는 가상 예시로 표시하고 실제 매핑과 QX 의미는 확인 필요로 남긴다. ID 자체를 재번호하지 않는다.

## 4. 내용 반복과 수정 후 전체 검토

입력: R-01의 의미를 보존해 첫 절을 수정한 뒤 마지막 절에 “자료를 임의로 채우지 않는다”와 근거 없는 “매핑 완료”가 남아 있다.

판정: 첫 절의 교정과 ID 보존만으로 통과하지 않는다. 전체를 재검토해 작업 규칙을 분리하고 완료 주장을 미확정 상태와 일치시킨다. 서식 검사가 통과해도 내용 검토는 별도다.

## 5. 목적·수정 범위 예외

입력 A: 고객 지정 목차의 회의록. 입력 B: 작성자를 위한 문서 작성 지침. 입력 C: 기존 문서의 표 정렬만 수정 요청.

판정: A에 현황→문제→개선→요구사항 목차를 강제하지 않는다. B에서는 작성 규칙 자체가 독자용 내용이므로 제거하지 않는다. C에서는 본문 문제를 발견해도 임의로 개작하지 않고 별도 보고한다.

## 6. 라우팅과 자료 부족

입력 A: “가상 공정 자료로 일반 요구사항정의서를 작성해줘.” 내용이 미확정이다. 입력 B: “공고 공식 양식으로 사업계획서를 작성해줘.”

판정: A는 일반 산출물 내용 참조와 필요한 질문으로 준비하며 사업계획서 전용 스킬로 자동 전환하지 않는다. B는 기존 draft/revise·공식 양식·preflight 경로를 유지한다. 어느 쪽도 최초 별도 동의 게이트를 생략하지 않는다.
