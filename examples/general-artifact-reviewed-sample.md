# 1. 현장분석

## 1.1 공정 현황

가상 조립라인은 공정 A~C로 구성된다. 분석 근거는 수용시험용 합성 공정 자료이다.

## 1.2 신호 대응관계

설비 EQ-01의 상태 신호 대응관계는 미정이다. 설비별 상태 집계를 위해 설비 식별자와 상태 신호의 대응관계를 정의해야 하며, 확정 전에는 집계 대상 연결을 완료할 수 없다.

# 2. 요구사항

## 2.1 상태 집계

| 요구사항 ID | 기능 | 선행 결정 |
|---|---|---|
| R-01 | 설비별 상태 집계 | EQ-01의 상태 신호 대응관계 확정 필요 |

정지 판정 임계값은 제공되지 않아 결정이 필요하다.

## 2.2 식별자 설명

- R-01은 기존 요구사항의 식별자이며 설비별 상태 집계 기능을 가리킨다.
- EQ-01은 합성 자료의 설비 식별자다. 요구사항 ID와 동일한 식별 체계가 아니다.
- DB10.DBX0.0은 신호 주소를 구별하기 위한 가상 예시이며 EQ-01의 실제 대응 주소가 아니다. 실제 주소와 대응관계는 확인이 필요하다.
- QX의 의미와 코드 내부 구성은 자료에 정의되지 않아 확인이 필요하다.
