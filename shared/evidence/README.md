# 평가 근거 레지스터

`evaluator-evidence-register.csv`는 업로드된 8개 선정평가의견 대비표를 사업 프로파일 수준으로 요약한 레지스터임

- 평가의견 원문이 근거이며 반영내용은 별도 대응 사례로 취급함
- 현재 레지스터는 모든 의견을 한 문장씩 전수 코딩한 완전한 데이터셋이 아니라, Skill 구조 고도화를 위한 대표 관점 레지스터임
- 새 자료 반영 시 원문 위치와 근거유형을 보존하고 행을 추가함
- 동일 사업의 반복은 `profile-rule`로 유지함
- 서로 다른 사업군의 반복이 누적되면 `core-candidate` 승격을 검토함
- 파일에 포함된 기업명·세부명은 출처 식별을 위한 것으로 외부 배포 시 익명화할 수 있음
