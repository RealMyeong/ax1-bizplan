# 공통 사업비·구매비용 관리대장 작성

## 양식 구조

| 시트 | 역할 | 입력·보존 경계 |
|---|---|---|
| `00_통합현황` | 승인·계획·전망·실구매·정산 집계, 경고와 차트 | 집계 수식과 차트 유지 |
| `01_구매비용원장` | 한 행 = 한 세부 품목·용역 | 7~156행, 150건 기본 용량 |
| `02_승인예산` | 공식 승인예산 기준원장 | 7~66행, 60개 예산라인 기본 용량 |
| `03_코드_안내` | 코드, 운영원칙, 공통양식 개정 내역 | 기관 자리표시자와 드롭다운을 함께 설정 |

원장 자동열은 `E, G, R, Y, AA, AB, AF, AH, AQ`, 승인예산 자동열은 `H:Q`임. 그 외 셀도 표제·안내·승인 기준과 실제 입력자료를 구분해 처리함. 특히 승인금액은 예상 구매금액으로 덮어쓰지 않음.

- 기본 제공 양식은 실제 거래와 승인예산이 없는 빈 양식임. 원래 4개 시트의 이름·순서·표 범위·병합·차트·열너비·행높이·서식·조건부서식을 유지함.
- 주문주체는 `주관기관 / 참여기관 1 / 참여기관 2` 자리표시자임. 사용자 자료로 실제 기관을 확정할 때 `03_코드_안내!F5:F7`과 원장 `AJ7:AJ156`의 드롭다운을 함께 갱신함. 예시를 실제 참여기관으로 간주하지 않음.
- ID는 고유하게 유지하고 예산라인ID로 승인예산과 세부품목을 연결함. 여러 품목에 같은 승인한도를 반복 복사해 합산하지 않음.
- 숫자는 원 단위 숫자, 날짜는 날짜값으로 입력함. 원본이 천원 단위면 근거 단위를 기록하고 ×1,000 변환함. 빈칸은 미확인, 0은 확인된 영으로 구분함.
- 계획·견적·계약·실구매·인정집행은 다른 단계임. 중복 차감하지 않고 원래 수식을 보존함. 전망액은 취소·제외를 빼고 `실구매 → 계약 → 선정견적 → 계획` 순서임.
- 양식은 VAT `별도`일 때 10%를 가산함. 이는 제공 양식의 계산 가정이며 모든 거래에 적용되는 판단이 아님. 면세·포함·확인필요를 실제 증빙에 맞춰 선택하고 세무·인정집행 결론을 추정하지 않음. 공식 R&D 사업이면 제출 완료 계획서·승인 변경문서가 기준이며 일반 내부 사업이면 해당 승인예산 자료를 사용함.
- 용량을 넘으면 조용히 표 밖에 추가하지 않음. 행 확장을 알리고 표·수식·집계 참조·드롭다운·조건부서식·차트 범위를 함께 확장해 첫·중간·마지막·추가행을 검증함.

## 파일명과 이력

- 새 사업비 원장에는 `BUD`를 사용함. 예: `DXS-AX-BUD-사업비_구매비용_관리대장-20260907-v0.1.xlsx`. 실제 사업은 확정된 사업코드를 사용함.
- 원본 이름에 있던 `CORP-MGT`나 관리번호를 신규 프로젝트의 기본값으로 복사하지 않음. 용어사전 규칙을 따르되 기존 파일은 일괄 개명하지 않고 다음 정식 개정에서 이전 이름을 기록하고 전환함.
- 양식 v1.1 및 `03_코드_안내`의 양식 개정 기록은 출처임. 프로젝트 산출물 버전과 구분해 보존함. `00_통합현황!A2`에는 확정한 프로젝트 문서코드·관리기간·문서 버전·수정일을 명시하고 기존 단위·색상 안내는 유지함. 파일명과 프로젝트 개정 이력을 동일하게 기록하며 템플릿 이력을 프로젝트 승인 이력으로 바꾸지 않음.
- 기존 승인본·제출완료본을 읽기·검토만 할 때는 이력 추가나 파일명 변경을 하지 않음.

## 검증

1. 수정 전후 시트·표·수식·셀 서식·병합·차트·드롭다운과 입력값을 비교하고 의도하지 않은 변경을 되돌림.
2. 재계산하고 오류 셀·누락/중복 ID·잘못된 예산 매핑·날짜·증빙 누락·예산 초과를 확인함. 정상 표시만 보고 승인 완료로 판단하지 않음.
3. 합성 테스트 또는 작업용 사본에서 계획수량 2, 단가 10,000, VAT 포함이면 계획금액 20,000인지, VAT 별도이면 22,000인지 확인함. 선정견적·계약·실구매 입력 시 전망 우선순위와 취소·제외의 0 반영도 확인하고 시험값은 최종본에서 제거함.
4. 승인예산별 집계와 통합현황을 독립 합산과 대조함. 원래 통합현황 비목표·차트는 5개 비목(인건비~연구수당)만 표시하므로 위탁연구개발비·간접비·기타를 사용하는 경우 해당 비목이 요약에서 빠지지 않도록 영향 범위를 알리고 별도 보완·검증함. 이번 공통화는 원래 집계식을 임의 변경하지 않았음.
5. 변경 화면과 영향을 받는 차트·집계를 렌더링해 확인하고 XLSX를 다시 열어 재확인함. 실제 Excel의 열림·계산·드롭다운·차트 검증을 못 했으면 명시함.

`check_budget_template.py`는 설치된 **빈 템플릿의 무결성** 검사임. 채워진 사용자 원장은 해시가 달라지는 것이 정상이며 이 검사로 실제 원장을 승인하지 않음.
