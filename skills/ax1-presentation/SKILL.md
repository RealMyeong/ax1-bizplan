# 목적과 경계

AX1 보고·제안·사업 발표자료를 청중의 판단 흐름에 맞는 PPTX와 발표자 노트로 만든다. 사업계획서 본문은 `bizplan-draft`·`bizplan-revise`, 사업계획서의 제출 점검은 `bizplan-preflight`로 구분한다. 발표자료 평가만 요청하면 읽기 전용으로 검토한다.

# 작업 시작 전 사용자 이해 확인

[사용자 이해 확인](references/05-user-confirmation-gate.md)에 따라 목적·입력·청중·시간·범위와 제외·산출물·편집성과 시각 품질을 설명하고, 별도 메시지의 동의 뒤 자료 조회·도구 사용을 시작한다. [범위와 실행 판단](references/14-task-execution.md)을 적용한다.

# 입력과 제작 모드

동의 후 목적·청중·발표시간 또는 장수·최신 기준자료를 확인한다. 메시지·브랜드·민감정보·최종 사용처는 결과에 필요한 만큼 확인한다. 제공된 값을 재질문하거나 자료에 없는 수치·실적·고객·기관 합의를 만들지 않는다.

기본은 전체 슬라이드 이미지형 PPTX다. 내부 텍스트·도형·차트는 개별 편집할 수 없음을 알리되 기본 모드를 매번 다시 선택하게 하지 않는다. 사용자가 개별 요소 편집을 명시하면 네이티브 모드를 적용한다. 승인된 이미지 생성 기능이 없어서 모드를 바꾸어야 할 때는 네이티브 또는 스토리보드 대안을 설명하고 확인받는다.

외부 이미지 API·제3자 API 키·사용자 홈의 자격증명 탐색·런타임 자동 설치는 하지 않는다. 현재 승인된 제작 기능을 사용하며 다른 형식이나 모드로 조용히 바꾸지 않는다.

# 단계별 제작

전체 신규·전면 개편은 [워크플로](references/01-presentation-workflow.md)를 읽고 다음 결정을 거친다. 사용자가 이미 확정한 동일 구성·스타일은 다시 묻지 않되 이미지 샘플 승인을 추정하지 않는다. 기존 자료의 좁은 수정은 승인된 스토리·스타일·모드를 유지하고 영향 범위만 처리한다.

1. [스토리보드와 시각 방향](references/02-storyboard-and-style.md) 및 [스토리보드 틀](assets/presentation-outline-template.md)로 장별 주장·근거·시각·출처·노트 요점을 설계하고 사용자에게 확정받는다.
2. 시각 방향을 확인한다. 발표시간에 맞춰 내용 밀도를 조정하되 분당 장수는 고정 규칙으로 강제하지 않는다.
3. 이미지 모드는 대표 샘플 1장을 생성해 승인받은 뒤 전체를 생성한다. 네이티브는 템플릿·시각 방향이 불명확할 때만 샘플을 확인한다.
4. [이미지형 제작](references/03-image-deck-mode.md)의 승인된 16:9 이미지와 `scripts/assemble_image_deck.py`로 조립하거나, 사용 가능한 네이티브 제작·렌더 도구를 사용한다.
5. [검증과 인계](references/04-validation-and-delivery.md), [검수표](assets/slide-review-checklist.md)와 `scripts/check_presentation.py`로 내용·시각·순서·노트·출처를 확인한다. 전체 제작 결과의 모든 슬라이드를 렌더·관찰하며 샘플만으로 전수 통과라고 하지 않는다.

문구·수치·표현은 기준자료까지 추적 가능해야 한다. 실제 한글을 기록하고 코드 표기·ASCII 음역으로 대체하지 않는다. 노트에는 강조점·전환·수치 해석·예상 질문을 남긴다. 제작·렌더 도구가 없으면 가능한 스토리보드·문안까지만 제공하고 PPTX 완성이나 시각 검증을 주장하지 않는다.

# 버전과 인계

파일 생성·수정에는 [파일명·버전](references/06-artifact-version-management.md), 의미 변경에는 [최신본 연동](references/07-artifact-synchronization.md)을 적용한다. 새 후보와 필수 연동 후보 검증 전 기존 현재본·PDF·프리뷰를 덮어쓰거나 이동하지 않는다.

PPTX, 목적·청중·제작 모드, 슬라이드/노트 상태, 실제 수행한 검증·제한·현재/보관/연동 상태를 보고한다. 검증 기록을 산출물 본문이나 채팅에 반복해서 붙이지 않는다.

설치·업데이트 요청에만 [직전 설치본 백업](references/13-skill-backup-retention.md)을 적용한다.
