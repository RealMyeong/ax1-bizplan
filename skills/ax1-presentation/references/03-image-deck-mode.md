# 이미지형 PPTX 제작

## 적용 조건

전체 슬라이드 이미지 모드는 다음 조건을 모두 만족할 때 사용한다.

- 사용자가 강한 시각 통일성을 원한다.
- 텍스트·도형·차트의 개별 편집이 불가능하다는 제한을 이해하고 선택했다.
- 승인된 이미지 생성 기능을 현재 환경에서 사용할 수 있다.
- 스토리보드, 시각 방향, 대표 샘플 한 장이 확정됐다.

## 프로젝트 구조

```text
99_임시작업/발표자료/<버전>/
  images/
    slide_01.png
    slide_02.png
  speech.md
  validation/
10_제출본/
  <산출물군>_제출_vNN.pptx
```

이미지는 `slide_01.png`부터 빠짐없는 연속 번호를 사용한다. PNG 또는 JPEG를 허용하되 한 자료 안에서 크기와 화면비를 통일한다.

## 이미지 생성

- 슬라이드마다 확정된 제목·주장·필수 문구·권장 시각·금지 요소를 프롬프트에 포함한다.
- 실제 한글을 사용하고 생성 이미지 속 글자가 깨졌으면 통과시키지 않는다.
- 16:9 슬라이드는 16:9에 충분히 가까운 이미지로 만든다.
- 장비·사람·브랜드·제품을 사실처럼 합성할 위험이 있으면 개념도·도식 또는 승인된 실제 자산을 사용한다.
- 생성 직후 각 이미지를 열어 문구, 잘림, 왜곡, 대비와 스타일 일관성을 확인한다.

## 발표자 노트

`speech.md`는 다음 형식을 사용한다.

```markdown
## 슬라이드 1

첫 장에서 강조할 핵심 메시지와 전환문

## 슬라이드 2

수치 해석, 주의할 표현과 예상 질문
```

영문 `## Slide 1` 형식도 허용한다. 같은 번호를 두 번 쓰거나 없는 슬라이드 번호를 쓰지 않는다.

## 조립

스킬 폴더를 기준으로 다음과 같이 실행한다.

```powershell
python scripts/assemble_image_deck.py --project-root "<프로젝트 절대경로>" --image-dir "99_임시작업/발표자료/vNN/images" --speech "99_임시작업/발표자료/vNN/speech.md" --output "99_임시작업/발표자료/vNN/후보.pptx"
```

스크립트는 프로젝트 밖의 입력·출력, 번호 누락·중복, 손상 이미지, 화면비 오류와 기존 출력 덮어쓰기를 거부한다. 네트워크나 API 키를 사용하지 않는다.

## 구조 검사

```powershell
python scripts/check_presentation.py --project-root "<프로젝트 절대경로>" --pptx "99_임시작업/발표자료/vNN/후보.pptx" --expected-slides 12 --require-notes --require-full-slide-images
```

구조 검사는 시각 검증을 대신하지 않는다. 모든 슬라이드를 실제 이미지 또는 PDF로 렌더링해 전수 확인한 뒤에만 완료로 보고한다.
