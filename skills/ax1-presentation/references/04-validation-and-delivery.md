# 발표자료 검증과 인계

## 내용 검증

- 슬라이드 제목이 본문 근거로 뒷받침되는가
- 원문과 수치·단위·기간·기관·용어가 일치하는가
- 주장과 가정·계획·실적이 구분되는가
- 출처가 최신 기준자료까지 추적되는가
- 사업계획서에서 파생된 발표자료라면 KPI·예산·일정·역할·과업·실증이 현재본과 일치하는가

## 시각 검증

- 모든 슬라이드를 렌더링하고 순서대로 관찰한다.
- 텍스트 잘림, 개체 겹침, 화면 밖 배치, 저해상도와 저대비를 확인한다.
- 제목·본문·강조·출처의 계층과 여백이 일관적인지 확인한다.
- 표와 차트의 축·범례·단위·색상 의미가 오해를 만들지 않는지 확인한다.
- 프로젝터 또는 화면 공유 환경에서 읽을 수 있는지 확인한다.

## 발표 검증

- 발표시간 안에 핵심 메시지를 전달할 수 있는가
- 첫 장에서 목적을, 마지막 장에서 요청·결론·다음 행동을 알 수 있는가
- 발표자 노트에 전환문, 핵심 수치 해석과 예상 질문이 있는가
- 본편과 부록의 경계가 명확한가

## 기술 검증

- PPTX 패키지가 손상되지 않았고 다시 열리는가
- 슬라이드 수, 화면비와 노트가 스토리보드와 일치하는가
- 이미지형 모드는 각 슬라이드가 전체 화면 이미지 한 장으로 구성되는가
- 네이티브 모드는 필요한 텍스트·도형·표·차트가 실제로 편집 가능한가
- 외부 링크·폰트·영상·매크로 같은 의존성과 다른 PC에서의 위험을 보고했는가

## 인계

최종 파일, 기준자료, 스토리보드, 사용 자산, 생성 모드, 검증 결과와 알려진 제한을 함께 보고한다. 승인되지 않은 폰트·이미지·로고의 사용 권리는 생성 성공과 별도로 확인한다.
