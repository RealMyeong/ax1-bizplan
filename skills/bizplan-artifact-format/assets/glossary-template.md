# 용어집 - [과제 약칭]

과제의 모든 산출물이 같은 말을 쓰도록 하는 단일 원천임. 산출물 1장의 용어 정의 표는 여기서 필요한 행만 발췌함.
새 용어는 산출물에 먼저 쓰지 않고 이 표에 먼저 넣음. 표기 기본값(숫자·날짜)은 bizplan-artifact-format 의 서식 규칙을 따름

| 용어 | 영문·약어 | 정의 | 출처·근거 | 사용 산출물 | 비고 |
|---|---|---|---|---|---|
| (예) 불량 역추적 | Defect Traceback | 불량 발생 시점의 공정·설비·작업자 데이터를 거슬러 원인 후보를 찾는 기능 | 요구사항정의서 REQ-012 | 요구사항정의서, 화면정의서 | |
| | | | | | |
