# 산출물 서식 규칙

AX1 산출물(정의서·계획서 등 HWPX)에 적용하는 확정 서식이다. 값은 고정이며 사용자가 명시적으로 바꾸라고 한 경우에만 변경한다.

이 문서는 겉모양만 다룬다. 본문에 **무엇을 쓰고 무엇을 쓰지 않는지**는 [본문 내용 규칙](06-content-rules.md)에 있다.

값을 바꿀 때는 이 문서와 `scripts/hwpx_format.py` 의 상수를 **함께** 고친다.

## 규칙표

| 항목 | 값 | 적용 범위 |
|---|---|---|
| 글꼴 | 맑은 고딕 | 문서 전체. 예외 없음 |
| 대체 폰트 | 금지 | 맑은 고딕에 글리프가 없는 문자는 쓰지 않음 |
| 본문 글자 크기 | 10pt 고정 | 본문·표·목차 항목 |
| 본문 줄간격 | 160% | |
| 표 셀 줄간격 | 160% | 본문과 같은 값 |
| 표 1행 배경색 | `#D9D9D9` | 머리행이 있는 표 |
| 표 1행 맞춤 | 세로 중간 + 가로 가운데 | 머리행이 있는 표 |
| 표 글자처럼 취급 | 지정 (On) | 본문 표 (`treatAsChar="1"`) |
| 그림 | 가운데 정렬, 글자처럼 취급, 폭 본문 폭 이내 (기본 140mm) | 본문 그림 |
| 표·그림 캡션 | 대상 **아래**, `[표 1-1] 제목` / `[그림 1-1] 제목` | 본문 표·그림 전부 |

## 적용 범위 - 목차 다음부터

**서식은 목차 다음부터 적용한다.** 표지·문서 정보·개정 이력·목차는 기관 제출 양식이므로 손대지 않는다. [불가침 구간](03-front-matter-lock.md) 참조.

## 제목 계층

본문 10pt 고정은 본문 텍스트 기준이다. 제목은 아래 값만 쓰고 임의 크기를 만들지 않는다.
제목은 크기·굵기에 더해 **문단 위/아래 간격**과 **개요 스타일 태그**를 갖는다.
간격 단위는 pt (XML 은 HWPUNIT, 1pt = 100).

| 수준 | 용도 | 크기 | 굵기 | 위/아래 간격 | 스타일 태그 | 비고 |
|---|---|---|---|---|---|---|
| 1 | 장 (1. 문서 개요) | 15pt | bold | 0 / 10pt | 개요 1 | 새 쪽에서 시작 (`pageBreak="1"`) |
| 2 | 절 (1.1 목적) | 12pt | bold | 14pt / 5pt | 개요 2 | **장 제목 바로 다음이면 위 간격 8pt** (빈 문단은 건너뛰고 판정) |
| 3 | 항 (1.1.1) | 10.5pt | bold | 10pt / 3pt | 개요 3 | |
| 4 | 세부 항 (1.1.1.1) | 10.5pt | bold | 10pt / 3pt | 개요 4 | **3수준과 동일 서식**, 스타일 태그만 다름 |
| - | 본문·리스트 | 10pt | | | | |
| - | 표 머리행 | 10pt | bold | | | |
| - | 표 본문 | 10pt | | | | |

스타일 태그(styleIDRef)는 겉모습을 바꾸지 않는다. 한/글 [도구]-[제목 차례]의
'스타일로 모으기'가 이 태그로 제목을 찾는다. 문단모양의 heading 을 OUTLINE 으로
바꾸면 한/글이 개요 번호를 자동으로 덧붙여 본문의 번호와 겹치므로 **쓰지 않는다.**

표지 구간의 크기(11 / 13 / 24 / 32pt 등)는 불가침 구간이므로 이 표의 대상이 아니다.

## 목차 항목

장·절 2단계만 넣는다. 항 이하는 목차에 넣지 않는다.

| 수준 | 서식 | 스타일 태그 |
|---|---|---|
| 장 | 10pt bold, 들여쓰기 0 | 차례 1 |
| 절 | 10pt, 왼쪽 들여쓰기 10pt | 차례 2 |

쪽번호는 스크립트가 계산할 수 없어 넣지 않는다. 필요하면 한/글 [도구]-[제목 차례]
(스타일로 모으기)로 다시 만든다. 제목에 개요 스타일 태그가 붙어 있어 가능하다.

## 리스트 계층

불릿·번호 모두 최대 4수준. **4수준 기호·번호 형식은 3수준과 같고 들여쓰기만 한 단계 더 는다.**
1수준 기호는 `•`(U+2022)다. 큰 동그라미 `●` 는 쓰지 않는다.
접힌 줄이 머리 글자 뒤 글자 시작점에 맞도록 내어쓰기(intent 음수)를 쓴다.

| 수준 | 불릿 기호 | 번호 형식 | 왼쪽여백 |
|---|---|---|---|
| 1 | • | 1. | 내어쓰기 폭 |
| 2 | - | 가. | + 10pt |
| 3 | · | 1) | + 20pt |
| 4 | · | 1) | + 30pt |

- 내어쓰기 폭 = 머리 글자("• ", "가. " 등)의 실제 글자 폭. `left = (수준-1)×1000 + 내어쓰기`, `intent = -내어쓰기`
- 옛 규칙의 1수준 기호 `●` 는 소급 적용 때 `•` 로 바꾼다
- 번호는 자동 번호가 아니라 글자로 남긴다 (항목마다 별개 문단)
- 2수준 번호가 14(하)를 넘으면 숫자로 되돌린다

## 캡션 (표·그림)

**표와 그림 모두 캡션을 대상 아래에 둔다.** 표 위 캡션은 위반이며 `apply_artifact_format.py` 가 아래로 옮긴다.

| 항목 | 값 |
|---|---|
| 형식 | `[표 1-1] 제목`, `[그림 1-1] 제목`. 대괄호, 종류 뒤 한 칸, 장-순번, 닫는 괄호 뒤 한 칸 |
| 번호 | 장 번호 - 장 안의 순번. 표와 그림은 따로 센다. 장이 바뀌면 1부터 |
| 위치 | 표: 표를 담은 문단 **바로 다음** 문단. 그림: 그림 바로 다음 문단 |
| 서식 | 10pt 보통 굵기, 가운데 정렬, 위 3pt / 아래 10pt (`CAPTION_MARGIN`) |
| 본문 참조 | 캡션이 있는 표·그림은 본문에서 한 번 이상 `표 1-1` 또는 `[표 1-1]` 로 언급 |

**캡션은 스크립트가 만들지 않는다.** 사람이 원고나 한/글에 `[표 1-1] 제목` 처럼 번호까지 직접 적는다.
그렇게 적힌 문단은 서식 적용 단계가 위 서식으로 맞추고, 표 위에 있으면 표 아래로 옮긴다.
캡션이 없는 표는 위반으로 잡지 않는다. 캡션이 있을 때만 서식·위치·번호·참조를 검사한다.

그림 캡션의 위치는 검사하지만 옮기지는 않는다. 그림은 자리표시 순서대로 들어가므로
캡션이 그림 위에 있으면 원고를 고치는 것이 맞다.

## 그림

본문 그림은 마크다운 자리표시로 넣는다. 생성 단계가 그림 파일을 BinData 에 넣고 본문에
배치하므로 별도 삽입 도구가 필요 없다. 문법과 사용법은 [본문 작성과 생성](04-content-authoring.md)의 「그림」에 있다.

| 항목 | 값 |
|---|---|
| 배치 | 가운데 정렬 문단 하나에 그림 하나. 글자처럼 취급(`treatAsChar="1"`) |
| 기본 폭 | 140mm. 자리표시에 `120mm` / `120x70mm` 로 지정 가능 |
| 폭 상한 | 본문 폭(쪽 폭 - 좌우 여백). 넘으면 본문 폭으로 줄이고 경고 |
| 높이 | 지정하지 않으면 원본 비율 |
| 형식 | png, jpg, bmp, gif |
| 줄 배치 캐시 | 표 문단과 같이 **본문 10pt 기준**. 그림 높이로 잡으면 줄간격 160% 가 그림 높이의 60% 만큼 빈 자리를 덧붙인다 |
| 등록 | `Contents/content.hpf` 의 `opf:item` 에 `isEmbeded="1"` 로. 이 값이 없으면 한/글이 그림을 버린다 |
| ZIP | `BinData/*` 는 무압축(STORED). 압축하면 한/글이 변조로 판정해 열지 않는다 |

그림 파일이 없거나 지원하지 않는 형식이면 문서를 만들지 않고 중단한다. 표 안 그림과
어울림(글자 옆 흐름) 배치는 이 경로에서 다루지 않는다.

## 개정 이력과 파일명 버전

개정 이력표(개정일자 | 버전 | 개정내역 | 작성자 | 확인자)는 불가침 구간에 있지만
**내용 기입만 예외로 허용한다.** 서식(글꼴·크기·음영·정렬)과 칸 구조는 양식 그대로 둔다.

| 규칙 | 값 |
|---|---|
| 비어 있으면 | 오늘 날짜(YYYY-MM-DD)와 `v0.1` 로 첫 행을 기록 |
| 비어 있지 않으면 | 마지막 버전을 한 단계 올려(`v0.2` -> `v0.3`) 다음 빈 행에 기록 |
| 빈 행이 모자라면 | 마지막 행을 복제해 행을 추가 (서식 그대로, rowCnt·표 높이 갱신) |
| 버전 표기 | 기본 `v0.x`. 소수점 없는 `v2` 는 `v2.1` 로 올린다 |
| 파일명 | 버전 조각(`_v0.x` 등)을 개정 이력 최신 버전과 **동일하게** 맞춘다. 조각이 없으면 `_v0.x` 를 붙인다 |
| 멱등 | 마지막 행이 오늘 날짜 + 같은 개정내역이면 다시 기록하지 않는다 |

`apply_artifact_format.py` 는 기본으로 기록하며 `--rev-note`(개정내역), `--rev-author`(작성자),
`--no-revision`(끄기)을 받는다. `build_artifact.py` 의 기본 개정내역은 `최초 작성` 이다.

## 표기 기본값 (숫자·날짜)

가장 널리 쓰는 형태로 고정한다. 아직 **검사·자동 교정은 하지 않는다.** 원고를 쓸 때 따르고, 검토 때 눈으로 본다.

| 항목 | 값 | 예 |
|---|---|---|
| 숫자 | 반각 아라비아 숫자, 천 단위 콤마, 소수점은 온점 | `1,234`, `0.85` |
| 단위 | 숫자에 붙여 쓴다 (%, 개, 명, 건, 회, mm, kg, ms 모두) | `15%`, `10개`, `3.2kg` |
| 범위 | 물결표, 양쪽 붙임. 단위는 뒤에 한 번 | `10~20%`, `2026-01-01~2026-12-31` |
| 날짜 | `YYYY-MM-DD` (개정 이력표와 같은 형식) | `2026-09-07` |
| 연월만 | `YYYY년 M월` | `2026년 9월` |
| 시각 | 24시간 `HH:MM` | `14:30` |
| 연차 | `1차년도`, `2차년도` | |

## 용어집

과제마다 용어집 파일 하나를 두고, 각 산출물 1장의 용어 정의 표는 여기서 발췌한다.

- 위치: 과제 폴더 최상위 `용어집.md` (bizplan-prepare 구조면 `02_사업기획_구현구상/용어집.md`)
- 양식: [용어집 템플릿](../assets/glossary-template.md)
- 같은 개념은 산출물마다 다른 말로 쓰지 않는다. 새 용어가 생기면 산출물이 아니라 용어집에 먼저 넣는다
- 영문 약어의 풀네임 표기 규칙은 아직 정하지 않았다

## 한/글 후처리 (스크립트가 못 하는 것)

| 항목 | 규칙 | 방법 |
|---|---|---|
| 쪽번호 | 하단 가운데, 본문 구간에 표시 | 한/글 [쪽]-[쪽 번호 매기기] |
| 머리말·꼬리말 | 기본 없음. 대외비 표시는 과제별로 결정 | |
| 표 안 그림 | 셀 안에 넣어야 하는 그림 | 한/글에서 직접 삽입 |
| 화면 캡처 | 실제 화면. 개인정보·얼굴·거래정보는 마스킹 | |

## 판단이 필요한 경우

- **머리행이 없는 표**: 1열만 음영인 라벨열 표는 "1행 음영" 대상이 아니다. 1행 전체를 칠하면 값 셀까지 회색이 되므로 그대로 둔다.
- **열 너비**: 한 단어가 셀 폭보다 넓으면 단어 중간이 잘린다. 이는 "글자 깨지지 않게"에 걸린다. 표 전체 폭은 유지한 채 열 너비를 재배분한다.
- **표지와 공유하는 정의**: 배경색·문단모양은 문서 전역이다. 표지 구간이 쓰는 정의를 그대로 고치면 양식까지 바뀐다. 반드시 사본을 만들어 본문에만 물린다.
