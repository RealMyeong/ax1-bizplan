# 산출물 서식 규칙

AX1 산출물(정의서·계획서 등 HWPX)에 적용하는 확정 서식이다. 값은 고정이며 사용자가 명시적으로 바꾸라고 한 경우에만 변경한다.

값을 바꿀 때는 이 문서와 `scripts/hwpx_format.py` 의 상수를 **함께** 고친다.

## 규칙표

| 항목 | 값 | 적용 범위 |
|---|---|---|
| 글꼴 | 맑은 고딕 | 문서 전체. 예외 없음 |
| 대체 폰트 | 금지 | 맑은 고딕에 글리프가 없는 문자는 쓰지 않음 |
| 본문 글자 크기 | 10pt 고정 | 본문·표·목차 항목 |
| 본문 줄간격 | 160% | |
| 표 셀 줄간격 | 160% | 본문과 같은 값 |
| 표 1행 배경색 | `#D9D9D9` | 머리행이 있는 표 |
| 표 1행 맞춤 | 세로 중간 + 가로 가운데 | 머리행이 있는 표 |
| 표 글자처럼 취급 | 지정 (On) | 본문 표 (`treatAsChar="1"`) |

## 적용 범위 - 목차 다음부터

**서식은 목차 다음부터 적용한다.** 표지·문서 정보·개정 이력·목차는 기관 제출 양식이므로 손대지 않는다. [불가침 구간](03-front-matter-lock.md) 참조.

## 제목 계층

본문 10pt 고정은 본문 텍스트 기준이다. 제목은 아래 값만 쓰고 임의 크기를 만들지 않는다.
제목은 크기·굵기에 더해 **문단 위/아래 간격**과 **개요 스타일 태그**를 갖는다.
간격 단위는 pt (XML 은 HWPUNIT, 1pt = 100).

| 수준 | 용도 | 크기 | 굵기 | 위/아래 간격 | 스타일 태그 | 비고 |
|---|---|---|---|---|---|---|
| 1 | 장 (1. 문서 개요) | 15pt | bold | 0 / 10pt | 개요 1 | 새 쪽에서 시작 (`pageBreak="1"`) |
| 2 | 절 (1.1 목적) | 12pt | bold | 14pt / 5pt | 개요 2 | |
| 3 | 항 (1.1.1) | 10.5pt | bold | 10pt / 3pt | 개요 3 | |
| 4 | 세부 항 (1.1.1.1) | 10.5pt | bold | 10pt / 3pt | 개요 4 | **3수준과 동일 서식**, 스타일 태그만 다름 |
| - | 본문·리스트 | 10pt | | | | |
| - | 표 머리행 | 10pt | bold | | | |
| - | 표 본문 | 10pt | | | | |

스타일 태그(styleIDRef)는 겉모습을 바꾸지 않는다. 한/글 [도구]-[제목 차례]의
'스타일로 모으기'가 이 태그로 제목을 찾는다. 문단모양의 heading 을 OUTLINE 으로
바꾸면 한/글이 개요 번호를 자동으로 덧붙여 본문의 번호와 겹치므로 **쓰지 않는다.**

표지 구간의 크기(11 / 13 / 24 / 32pt 등)는 불가침 구간이므로 이 표의 대상이 아니다.

## 목차 항목

장·절 2단계만 넣는다. 항 이하는 목차에 넣지 않는다.

| 수준 | 서식 | 스타일 태그 |
|---|---|---|
| 장 | 10pt bold, 들여쓰기 0 | 차례 1 |
| 절 | 10pt, 왼쪽 들여쓰기 10pt | 차례 2 |

쪽번호는 스크립트가 계산할 수 없어 넣지 않는다. 필요하면 한/글 [도구]-[제목 차례]
(스타일로 모으기)로 다시 만든다. 제목에 개요 스타일 태그가 붙어 있어 가능하다.

## 리스트 계층

불릿·번호 모두 최대 4수준. **4수준 기호·번호 형식은 3수준과 같고 들여쓰기만 한 단계 더 는다.**
접힌 줄이 머리 글자 뒤 글자 시작점에 맞도록 내어쓰기(intent 음수)를 쓴다.

| 수준 | 불릿 기호 | 번호 형식 | 왼쪽여백 |
|---|---|---|---|
| 1 | ● | 1. | 내어쓰기 폭 |
| 2 | - | 가. | + 10pt |
| 3 | · | 1) | + 20pt |
| 4 | · | 1) | + 30pt |

- 내어쓰기 폭 = 머리 글자("● ", "가. " 등)의 실제 글자 폭. `left = (수준-1)×1000 + 내어쓰기`, `intent = -내어쓰기`
- 번호는 자동 번호가 아니라 글자로 남긴다 (항목마다 별개 문단)
- 2수준 번호가 14(하)를 넘으면 숫자로 되돌린다

## 판단이 필요한 경우

- **머리행이 없는 표**: 1열만 음영인 라벨열 표는 "1행 음영" 대상이 아니다. 1행 전체를 칠하면 값 셀까지 회색이 되므로 그대로 둔다.
- **열 너비**: 한 단어가 셀 폭보다 넓으면 단어 중간이 잘린다. 이는 "글자 깨지지 않게"에 걸린다. 표 전체 폭은 유지한 채 열 너비를 재배분한다.
- **표지와 공유하는 정의**: 배경색·문단모양은 문서 전역이다. 표지 구간이 쓰는 정의를 그대로 고치면 양식까지 바뀐다. 반드시 사본을 만들어 본문에만 물린다.
