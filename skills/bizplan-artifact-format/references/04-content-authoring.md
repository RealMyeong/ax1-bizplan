# 본문 작성과 생성

`scripts/build_artifact.py` 는 `document_form/` 의 표지 양식을 그대로 두고 **목차 제목 뒤에 목차 항목과 본문을 이어붙인다.** 그런 다음 서식 규칙을 자동으로 적용한다.

```powershell
python scripts/build_artifact.py `
  --template "<저장소>/document_form/[산출물] 표지 양식.hwpx" `
  --content  "<본문>.md" `
  --title    "데이터수집 App 정의서" `
  --project  "[과제번호 RS-XXXX-XXXXXXXX] 사업명" `
  -o         "<출력>.hwpx"
```

`--title` 과 `--project` 는 표지의 자리표시자 **글자만** 바꾼다. 글꼴·크기·배치는 양식 그대로다.
`--no-toc` 를 주면 목차 항목을 만들지 않는다.

한/글이 없어도 동작한다. 표준 라이브러리만 쓴다.

## 마크다운 규칙

본문은 마크다운으로 쓴다. **목차 다음의 첫 `# 제목` 부터** 읽으므로, 마크다운 앞부분에 표지·문서정보·개정이력·목차가 들어 있어도 그대로 두면 된다. 그 부분은 양식이 이미 갖고 있다.

| 마크다운 | 결과 |
|---|---|
| `# 1. 문서 개요` | 장 제목 15pt bold, 새 쪽에서 시작 |
| `## 1.1 목적` | 절 제목 12pt bold |
| `### F-01. ...` | 항 제목 10.5pt bold |
| 빈 줄로 나뉜 문단 | 본문 10pt |
| `- 항목` | 리스트. 들여쓰기 2칸마다 한 단계, 불릿 `·` |
| `1. 항목` | 번호 목록. 번호를 글자로 남기고 **항목마다 별개 문단**으로 둠 |
| `\| a \| b \|` | 표. **첫 줄이 머리행**, 구분선 줄(`\| --- \|`)은 무시 |
| `---` | 무시 |

인라인 `**굵게**`, `` `코드` ``, `[링크](url)` 는 표시만 제거하고 글자는 남긴다.

## 목차

목차 항목은 마크다운의 **장 제목(`# `)** 에서 자동으로 뽑는다. 목차 *제목* 문단(`목      차`)은 양식의 것을 그대로 쓰고, 그 뒤에 항목을 붙인다.

쪽번호는 넣지 않는다. 필요하면 한/글 [도구]-[제목 차례]로 다시 만든다.

## 표 기본 속성

생성하는 표는 한/글 [표 속성]에서 다음 상태가 된다. 값은 `scripts/build_artifact.py` 상단 상수로 관리한다.

| 한/글 설정 | 값 | XML |
|---|---|---|
| 글자처럼 취급 | **해제** | `hp:pos@treatAsChar="0"` |
| 쪽 경계에서 | **셀 단위로 나눔** | `hp:tbl@pageBreak="CELL"` |
| 제목 줄 자동 반복 | **끔** | `hp:tbl@repeatHeader="0"`, 머리행 `hp:tc@header="0"` |

글자처럼 취급을 해제하면 표가 글자 흐름에 끼워지지 않고 문단에 붙은 개체가 된다. 어울림은 `textWrap="TOP_AND_BOTTOM"`(자리 차지)이라 위아래로 본문이 흐른다.

양식 구간(표지의 문서 정보표·개정 이력표)은 이 설정을 적용하지 않는다. 양식 그대로 둔다.

## 열 너비

표 열 너비는 열별 최장 내용에 비례해 나눈다. 그 뒤 서식 적용 단계가 **단어가 잘리는 열을 다시 넓힌다.** 표 전체 폭은 본문 폭에 맞춰 고정된다.

## 줄바꿈과 글자 겹침

각 문단은 실제로 접히는 줄 수만큼 `hp:lineseg` 를 갖는다. 이 값이 모자라면 여러 줄이 **한 자리에 겹쳐 그려진다.** 한/글이 열 때 다시 계산하지만 그 전에 그려지는 화면은 겹친 상태가 된다.

줄 수는 맑은 고딕의 실제 글자 폭으로 계산하되, 한/글의 줄나눔을 정확히 재현할 수 없으므로 `WRAP_SAFETY`(0.97)만큼 좁게 잡아 **적게 세지 않도록** 한다. 많이 세는 쪽은 빈 줄이 하나 생기는 정도로 그친다.

번호 목록을 한 문단으로 뭉치면 아주 긴 문단이 되어 이 문제가 크게 드러난다. 그래서 항목마다 문단을 나눈다.

## 아직 안 되는 것

| 항목 | 대응 |
|---|---|
| 그림·다이어그램 | 한/글에서 직접 넣은 뒤 `apply_artifact_format.py` 로 서식만 다시 맞춘다 |
| 쪽번호 | 한/글 [쪽]-[쪽 번호 매기기] |
| 병합 셀 | 마크다운 표에 표현할 수 없다. 생성 후 한/글에서 병합 |
| 각주·미주 | 미지원 |

## 생성 후 확인

1. `python scripts/check_artifact_format.py <출력>.hwpx` — 위반 0건
2. 원본 마크다운의 텍스트 조각이 문서에 모두 있는지 대조
3. 양식 구간이 템플릿과 바이트 단위로 같은지 확인
4. 한/글에서 열어 표지·표·쪽나눔을 직접 관찰
