# 경량 HWPX 모드의 구조와 안전 경계

## 목적

표준 라이브러리만으로 승인된 AX1 템플릿에 확정 Markdown 본문을 넣는다. 한컴오피스·COM·pyhwpx를 실행하지 않으므로 창, 승인 팝업, 프로세스 잠금 없이 자동화와 CI에서 사용할 수 있다.

## 지원 범위

- 스킬에 포함된 `assets/templates/template-manifest.json`의 SHA-256과 일치하는 템플릿
- ZIP 기반 HWPX, `mimetype` 첫 항목·무압축
- `Contents/section0.xml` 하나만 있는 단일 섹션 문서
- 제목, 일반 문단, 단순 목록, 병합되지 않은 Markdown 표
- 본문과 표 셀 줄간격 160%

다중 섹션, 암호화, 전자서명, 임의 템플릿, 그림 추가·교체, 병합 셀, 각주·미주, 변경추적, 임의 기존 문서 재서식은 경량 모드에서 처리하지 않는다. 이 경우 결과 파일을 쓰지 않고 upstream `hwpx` 경로로 전환한다.

## 저장 원칙

1. 승인 템플릿의 SHA-256과 ZIP·XML 구조를 먼저 검증한다.
2. 대상 폴더에 임시 파일을 만들고 본문 생성과 서식 적용을 수행한다.
3. XML 파싱, CRC, 필수 부품, 줄간격, 글꼴 참조, 표 머리행, 잔여 자리표시자를 검사한다.
4. 표지·본문·표 셀의 한글이 UTF-8 실제 문자로 남았는지 확인하고, 한글 코드 표기나 ASCII 대체가 있으면 실패시킨다.
5. 모두 통과한 파일만 원자적으로 최종 경로로 교체한다.
6. 원본 템플릿은 수정하지 않는다.

경량 검사는 실제 한컴 조판을 증명하지 않는다. 제출 후보는 upstream 구조 검증과 전체 페이지 한컴 관찰을 추가로 거친다.

## 의존성 정직성

스크립트는 Python 표준 라이브러리만 import한다. Windows에서 맑은 고딕 TTF를 읽을 수 있으면 실제 폭 메트릭을 사용하고, 없으면 `unicodedata` 기반 보수적 폭 추정으로 동작한다. 후자의 결과는 정확한 글리프 검증으로 표현하지 않는다.
