# 승인 템플릿과 표지 경계

## 승인 기준

경량 모드는 `assets/templates/template-manifest.json`에 등록된 파일 하나만 기본 템플릿으로 사용한다. 파일명뿐 아니라 SHA-256이 일치해야 한다. 해시가 달라지면 사용자가 새 템플릿을 승인하고 검증 자료와 매니페스트를 함께 갱신하기 전까지 중단한다.

배포 템플릿에는 실제 과제번호·사업명·개인정보를 넣지 않는다. 표지에는 다음 자리표시자만 둔다.

- `[발주기관]`
- `[사업명]`
- `[과제번호]`
- `[세부 사업명]`
- `[산출물 제목]`
- `[문서 유형]`

## 불가침 경계

`목 차` 제목 문단의 끝까지를 승인 표지 영역으로 본다. 경량 생성기는 위 자리표시자의 텍스트와 그 문단의 줄 배치만 갱신한다. 문서 정보표·개정 이력표·로고·표 구조·표지 서식은 바꾸지 않는다.

목차 제목을 찾지 못하거나 자리표시자 6종 중 하나라도 없으면 경계를 추정하지 않고 중단한다. 생성 결과에 자리표시자나 배포 금지 표본 값이 남아도 실패한다.

## 템플릿 교체

새 템플릿을 배포하려면 다음을 모두 수행한다.

1. 실제 사업·기관·개인정보를 일반 자리표시자로 치환
2. HWPX CRC·XML·open-safety와 한컴 재개방 확인
3. 경량 생성 수용 테스트와 160% 규칙 검사
4. 템플릿 파일 SHA-256 및 매니페스트 갱신
5. PR에 출처·배포 권한·익명화 결과 기록

팀원이 가져온 실문서나 채워진 예시는 템플릿으로 커밋하지 않는다.
