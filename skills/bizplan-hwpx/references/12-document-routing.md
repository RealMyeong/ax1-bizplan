# 문서 유형별 양식 선택

HWPX 작업은 내용을 쓰기 전에 문서 목적과 양식의 권한을 먼저 구분한다.

## 최초 확인에서의 목적 분기

문서 목적은 두 가지다.

1. `사업계획서 작성`: 국가 R&D·공모 사업계획서의 초안·수정·공식 양식 반영
2. `일반 산출물 작성`: 정의서·설계서·분석서·보고서·회의록 등 업무 산출물 작성

- 문서 목적은 입력자료 이름보다 사용자가 요청한 최종 산출물을 우선해 정한다. `RFP를 기준으로 요구사항정의서를 작성`은 일반 산출물이고, `기존 사업계획서를 바탕으로 결과보고서를 작성`도 일반 산출물이다. 반대로 최종 산출물이 사업계획서이면 RFP·공고·공식 양식은 사업계획서 경로의 근거다.
- 최종 산출물이 사업계획서라고 명확하면 1번으로 추론하고 공고·RFP·제출기관 공식 양식을 기준으로 예상한다.
- 최종 산출물이 정의서·설계서·분석서·보고서·회의록 또는 AX1 산출물이라고 명확하면 2번으로 추론한다.
- 입력자료와 목표 산출물의 신호가 충돌하거나 목표 산출물이 생략됐을 때만 사용자에게 묻는다.
- 목적이 명확한 경우 선택 질문을 추가하지 않고, 최초 사용자 이해 확인문에 선택 결과·근거·양식 기준을 포함한다.
- `HWPX 문서를 만들어줘`처럼 목적에 따라 결과가 달라지는 요청만 두 선택지와 차이를 제시한다. 파일명이나 첨부 내용은 사용자 동의 전에 먼저 열지 않고 판정하지 않는다.
- 두 선택지 각각의 예상 입력·범위와 제외·산출물·가정과 위험까지 완전하게 설명한 뒤 사용자가 목적 선택과 진행 동의를 한 메시지에 함께 답하면 같은 확인을 반복하지 않는다. 선택지만 간단히 제시했거나 목적만 선택했다면 선택된 이해 내용을 완전하게 설명하고 공통 확인 게이트의 별도 진행 동의를 받는다.
- 계약·고객 필수 양식은 세 번째 문서 목적이 아니라 2번 일반 산출물의 양식 권한 우선순위다.
- 사업계획서에 공식 HWPX가 아직 없거나 자유양식이라고 적혀 있어도, 확인 뒤 공고 지침을 검토하기 전에는 AX1 일반 산출물 템플릿으로 자동 전환하지 않는다.

## 1. 국가 R&D·공모 사업계획서

- 공고기관이 제공한 공식 양식을 최우선으로 사용한다.
- 공식 제목·표·필드·페이지 제한과 작성지침을 보존한다.
- AX1 산출물 템플릿은 공식 양식의 대체재로 사용하지 않는다.
- 공식 HWPX 채움·기존 문서 편집은 upstream `hwpx` 경로를 사용하고, 내용 준비는 `bizplan-draft` 또는 `bizplan-revise`에서 완료한다.

## 2. AX1 일반 산출물

- 정의서, 설계서, 분석서, 계획서, 결과보고서, 회의록 등 별도 공식 양식이 없는 HWPX 산출물은 `assets/templates/template-manifest.json`에 등록된 승인 AX1 산출물 템플릿을 기본으로 사용한다.
- 확정 Markdown과 표지 정보가 있으면 표준 라이브러리 경량 모드로 생성한다.
- 본문과 표 셀 줄간격 160%, 실제 한글 문자 보존, 의미 기호 보존, 4단계 개요 규칙을 적용한다.
- 개별 스킬 ZIP 안의 템플릿만 사용하며 저장소 링크·정션이나 외부 `document_form` 폴더에 의존하지 않는다.

## 3. 별도 계약·고객 양식이 있는 일반 산출물

사용자가 특정 계약·고객 양식을 반드시 사용해야 한다고 명시하면 그 양식이 승인 AX1 기본값보다 우선한다. 다만 임의 양식을 경량 생성기에 넣지 않고 upstream `hwpx` 경로로 원본을 보존해 편집한다.

## 완료 보고

- 선택한 경로와 선택 근거
- 사용한 공식 양식 또는 승인 AX1 템플릿 ID·SHA-256
- 적용한 개요·줄간격 규칙과 예외
- 구조·readback·시각 검증 상태
