# 목적과 경계

국가 R&D·공모 사업계획서와 발표자료의 제출 준비 상태를 `준비 / 조건부 준비 / 보완 필요`로 판정하고 마지막 조치 목록을 제공한다. 신규 작성이나 전면적인 내용 개선을 시작하지 않는다.

# 작업 시작 전 사용자 이해 확인

[사용자 이해 확인](references/12-user-confirmation-gate.md)에 따라 목적·입력·점검 범위와 제외·결과·주요 가정을 설명하고, 별도 메시지의 동의 뒤 읽기 전용 탐색·점검을 시작한다. [범위와 실행 판단](references/14-task-execution.md)을 적용한다.

# 점검

동의 후 대화·폴더에서 제출 후보, 기준 공고·공식 양식·첨부 지침·발표자료를 찾는다. 이미 제공된 자료는 재요청하지 않는다. 전체 제출 점검은 아래 축을 확인하며, 특정 항목만 요청하면 점검 범위를 밝히고 전체 제출 준비 판정은 하지 않는다.

- 파일·버전: 올바른 공고·양식·과제·기관·최신 후보인지. [파일명·버전](references/10-artifact-version-management.md)에 따른 DXS 코드·날짜·버전과 내부 이력, 현재본 하나, 보관 경로·해시·변경일치
- 연동: [최신 산출물 연동](references/11-artifact-synchronization.md)의 기준 원천·현재 버전·필수 후보·미반영 변경 일치
- 양식·편집: [공통 기준](references/01-core-principles.md)과 [양식 가이드](references/02-format-style-guide.md)의 제목·표·들여쓰기·문체·페이지·글꼴·여백·서명·합계·첨부요건, 도표 설명·캡션·참조·잘림·고립 제목
- 완결성: TODO·TBD·자료 필요·예시문·안내문·빈칸, 미해당 표시, 주석·변경추적·숨김텍스트
- 수치·용어: 기간·예산·인원·가중치, 최종·연차·성과·요약·발표 수치, 개수·약어·단위·누적/연차·분자/분모
- KPI·증빙: [유형별 KPI 기준](references/04-kpi-framework.md)의 정의·목표·산정·시험/확인 방식·책임·증빙과 시장·최고 성능 주장 출처. 공인시험을 모든 지표에 일괄 강제하지 않는다.
- 역할·실증·위험: 직접개발과 외부제공 경계, 책임·결과물, 실증 승인·안전·중단·복귀, 지연·성능미달·데이터 부족 대응
- 사람 확인: 실제 수치·서명권자·목표 수용·기관 및 시험기관 합의·민감 도면/공정/개인/거래정보·최신 버전 확정. 기존 승인 근거가 있으면 재질문하지 않으며 없는 승인을 만들어 넣지 않는다.

# 파일·시각 검증

레이아웃 확인에는 [파일 처리·검증](references/07-artifact-workflow.md)을 적용한다. HWPX는 `bizplan-hwpx`의 원본 보존·SHA-256·엔진·open-safety·readback·프리뷰·한컴 전 페이지 관찰 증거가 실제 후보와 일치하는지 확인한다.

선택적으로 평문에 `python scripts/advisory_lint.py plan.txt --nominal-ending --no-terminal-period`를 실행한다. `--strict`는 고신뢰 오류용이며 자동검사는 직접 검토의 보조다. 키워드 부재만으로 실패시키지 않는다.

# 판정과 인계

- 결과·근거·중요 조치 순서·사람 확인·미검증 범위를 먼저 보고한다. 단순한 상태 질문에 모든 체크리스트를 반복 출력하지 않는다.
- HWPX 한컴 전체 페이지 관찰 증거가 없으면 내용이 통과해도 `준비`로 판정하지 않는다. 프리뷰 성공이나 앱 실행만으로 실제 관찰을 대체하지 않는다.
- 함께 제출하는 필수 산출물에 내용 불일치·`연동 대기`·`차단`·`승인 필요`가 남으면 Gate이며 `보완 필요`다. 이를 `조건부 준비`로 낮춰 우회하지 않는다.
- 읽기 전용 점검에서는 파일·버전 이력·연동현황을 수정·이동하지 않는다. 사용자 요청에 수정이 포함된 경우에만 최소 수정하고 필수 후보를 모두 검증한 뒤 현재본·보관본을 전환한다.
- 점검 승인은 실제 제출·외부 전송 권한이 아니다. 확인하지 못한 내용을 `이상 없음`으로 보고하지 않는다.

설치·업데이트 요청에만 [직전 설치본 백업](references/13-skill-backup-retention.md)을 적용한다.
