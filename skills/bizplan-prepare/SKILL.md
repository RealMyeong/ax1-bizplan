# 목적과 경계

사업계획서의 자료 수집·사업 구체화·작성·검토·제출·이전본 보관을 위한 작업공간을 멱등하게 준비한다. 프로젝트 내용 작성이나 기존 자료 정리는 수행하지 않는다.

# 작업 시작 전 사용자 이해 확인

[사용자 이해 확인](references/03-user-confirmation-gate.md)에 따라 목적·예상 대상 폴더·생성 범위와 제외·산출물·안전 가정을 설명하고, 별도 메시지의 동의 뒤 경로 조회·작업을 시작한다. [범위와 실행 판단](references/14-task-execution.md)을 적용한다.

# 실행

1. 사용자 지정 폴더를 우선하고 지정이 없으면 현재 프로젝트 최상위를 사용한다. 의도한 위치를 특정할 수 없을 때만 정확한 경로를 묻는다.
2. 존재하는 디렉터리인지 절대경로로 확인한다. 드라이브 루트·사용자 프로필 루트·스킬 설치 폴더는 대상에서 제외한다. 폴더 자리의 동명 파일 등 충돌이 있으면 생성 전에 중단한다.
3. [작업공간 생성기](scripts/setup_workspace.ps1)를 실행한다.

```powershell
& "<skill-folder>\scripts\setup_workspace.ps1" -Root "<absolute-project-root>"
```

기존 폴더·체크리스트·이력은 유지하고 없는 항목만 생성한다. 최상위 자료를 자동 이동·이름변경·삭제하지 않는다. 준비가 끝났다는 이유로 초안 작성을 시작하지 않는다.

최상위에 `사업계획서_준비현황.md`·`산출물_연동현황.md`, `98_이전버전`에 세 작업단계 보관 폴더와 `산출물_버전이력.md`를 만든다. 별도 최신본 복제 폴더는 만들지 않는다.

준비 작업은 빈 대장만 만든다. [버전 정책](references/01-artifact-version-management.md)·[연동 정책](references/02-artifact-synchronization.md)에 필요한 현재본·원천·상태를 추정해 채우거나 기존 파일을 보관함으로 이동하지 않는다.

# 검증과 보고

반환된 `created_directories`·`existing_directories`·`checklist_status`·`version_ledger_status`·`sync_ledger_status`와 실제 경로를 확인한다. 폴더 유형과 세 문서의 UTF-8·존재 여부를 검사한다. 재실행 시 기존 파일 해시와 내용이 유지되고 새 항목이 생기지 않는지 확인한다.

프로젝트 경로, 생성/기존 수, 준비현황·연동현황·버전 이력 링크, 미완료·충돌을 간단히 보고한다. 기존 파일은 명백한 경우 권장 분류 위치만 제안하며 실제 이동은 별도 요청·승인이 필요하다.

설치·업데이트 요청에만 [직전 설치본 백업](references/13-skill-backup-retention.md)을 적용한다.
