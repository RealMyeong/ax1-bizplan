# 산출물 버전 이력

주 작업공간에는 산출물군별 현재본 한 묶음만 두고, 이전본은 `98_이전버전` 아래에서 보관함. 경로는 프로젝트 최상위 폴더 기준 상대경로로 기록함

서로 다른 현재 산출물 사이의 항목별 기준 원천과 내용 연동 결과는 프로젝트 최상위의 `산출물_연동현황.md`에 별도로 기록함

| 산출물군 | 버전 | 상태 | 단계 | 주 파일 | 연관 파일 | 주 파일 SHA-256 | 생성·확정 시각 | 보관 시각 | 기준·검증·복구 메모 |
|---|---|---|---|---|---|---|---|---|---|
|  |  | `현재 / 보관 / 검증대기` |  |  |  |  |  |  |  |

## 운영 메모

- 같은 산출물군의 `현재` 행은 하나만 유지함
- 제출처·고객 필수 이름이 없으면 주 파일과 연관 파일에 `DXS-[사업코드]-[문서유형]-[파일제목]-[YYYYMMDD]-vX.Y.[확장자]`를 적용함
- 기존 파일명을 다음 정식 개정에서 DXS 표준으로 전환하면 이전 이름과 새 이름을 마지막 열에 함께 기록함
- 제출처·고객 필수 파일명 예외는 적용 근거와 내부 DXS 작업본·검증본의 대응 관계를 마지막 열에 기록함
- 새 버전 검증이 끝난 뒤에만 기존 현재본을 `보관`으로 바꿈
- 연관 파일이 여러 개면 Markdown 표가 깨지지 않도록 세미콜론 또는 `<br>`로 구분함
- 보관본을 다시 사용하면 원본 보관 행을 유지하고, 이를 기준으로 만든 새 버전 행을 추가함
- 파일 이동 실패, 이름 충돌과 사람이 지정한 예외는 마지막 열에 기록함
