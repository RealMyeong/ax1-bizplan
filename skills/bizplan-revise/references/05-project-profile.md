# 사업 프로파일: 2026 PI-LAM 제조 Physical AI

## 적용조건

다음 조건이 확인될 때만 적용함

- `인간-AI 협업형 LAM 개발·글로벌 실증` 사업 또는 직접 연계 세부과제
- 제조 공정 융합데이터, PINN·PI-LAM·Physical AI Agent, 현장 실증이 핵심인 과제
- RFP와 공식 양식이 본 프로파일보다 우선함

## 추가 검토 항목

### 공정 도메인 카드

공정별로 다음을 한 묶음으로 확인함

- 대상 제품·소재·설비·공정 단계
- 품질 CTQ, 불량·고장·안전위험
- 주요 입력·출력 변수
- 물리현상, 지배관계, 경계·초기조건
- 센서·검사장비·수집주기·해상도
- 독립 Ground Truth
- 예측·추론 결과와 제어·권고 대상
- 적용범위와 유효범위

### 데이터 카드

- 공정·기업·행동 데이터의 발생원
- 텍스트·이미지·영상·음성·시계열·이벤트 구분
- Raw·전처리·분석·AI Ready 등 RFP의 처리단계
- 공정·센서·연차별 규모와 산정식
- Timestamp, 제품·LOT·Cycle ID, 데이터 계보
- 결측·노이즈·드리프트·오매칭·통신손실 대응
- 정상·이상·경계·노후화·희소 불량 데이터 확보
- Training·Validation·독립 Test 구분
- 데이터-모델 적합성 중간점검과 수집계획 환류

### 모델·Agent 연계

- 총괄 범용모델과 세부 현장특화 범위
- 모델·데이터·인터페이스 전달물과 책임기관
- 오프라인 검증, 관찰운전, 권고, 승인형 적용, 제한제어의 단계
- 성능미달 시 데이터 보강, 재학습·재튜닝, 재검증과 변경이력
- Agent의 상태인지, 분석·예측, 원인분석, 조치추천, 승인·거절·수정, 결과환류 기능
- 권고-조치-품질결과의 추적 가능성

### 현장 안전과 Human-in-the-loop

- 작업자 승인범위와 자동제어 허용범위
- 설명근거, 신뢰도, 불확실성, 개입기준
- 수동전환, Hold, Fallback, Rollback, 기존 조건 복귀
- 기존 PLC·Safety PLC·Interlock과 AI 제어의 관계
- 통신·센서·모델 이상 및 레이턴시 대응

### 연차별 산출물

- 적용 공정·설비·라인 수
- 모델 또는 Agent의 개발·검증·실증 수준
- 데이터 처리단계와 누적규모
- 기관별 책임 산출물
- 총괄·세부 인터페이스 정의서, 시험절차서, 검증보고서 등

### 성과·사업화

- RFP 공통지표와 공정 특화지표를 구분함
- 공정 특화지표는 물리현상→품질영향→계측량으로 도출함
- 기술이전 패키지, 구축형·클라우드·운영서비스의 범위와 차이를 설명함
- 적용기업·라인, PoC, 기술이전, 매출, 유지관리의 목표와 증빙을 연결함
